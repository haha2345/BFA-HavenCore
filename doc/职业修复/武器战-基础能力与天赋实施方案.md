## 公共引擎

### ENG-01 施法费用与父子传递

- **问题：** `TakePower` 只写了 `PowerSpent.Rage`；触发子技能不继承父技能变量。斩杀倍率写在玩家对象上。
- **依据：** 计划约定仅新增内部施法上下文；`ProcEventInfo::GetProcSpell()` 可读取本次 Spell。
- **修改：** 在 [Spell.h](../../src/server/game/Spells/Spell.h) / [Spell.cpp](../../src/server/game/Spells/Spell.cpp) 增加白名单键与 `CopyCastContextFrom` / `TrySetOnceFlag`。[Unit::CastSpell](../../src/server/game/Entities/Unit/Unit.cpp) 在触发施法时拷贝费用、倍率与 OnceMask。`PowerSpent.Rage` 也拷贝给子技能以便斩杀返怒，愤怒掌控跳过 `IsTriggered()` 避免二次减冷却。免费光环把 Amount 置零时，战术专家默认回读 SpellPower 未减免费用。
- **构建结果：** 见文末。
- **待验收：** 父子技能费用是否只属于一次主动施法；延迟子技能仍能读到倍率。

## 核心循环

### ARMS-03 斩杀 163201 / 281000 Execute → 260798

- **问题：** 整数除法截断倍率；玩家共享变量；免费斩杀变 0 伤；返怒在父技能命中且不区分实扣。
- **依据：** 35662 163201 Dummy 20；231830 文案“存活才返还”；29725 Dummy 40；52437 含 -100% 费用。禁止照抄 SimC 不判死亡。
- **修改：** 浮点倍率写入本次 Spell；免费（52437 / 262228）按满费用口径；返怒在 260798 结算后对**原目标存活**且具备 231830 按实扣返还一次；成功施放才移除猝死增益。
- **构建结果：** 见文末。
- **待验收：** 低/中/高怒气；猝死、致命平静；击杀与未击杀。

### ARMS-01b 战术专家 184783 Tactician（边界）

- **问题：** 第一批已改压制充能，仍 `CalcPowerCost`，多目标可重复抽取。
- **依据：** 第一批账本剩余项；旧 SimC 注明计算费用≠实扣。
- **修改：** 读取 `Cost.TacticianRage`；同实例 OnceMask；触发子技能除 260798 外不抽。重置对象仍为压制充能（第一批，待验收）。
- **待验收：** 横扫双目标只抽一次；免费斩杀仍按满费用口径。

### ARMS-02b 愤怒掌控 152278 Anger Management（边界）

- **问题：** 需与新斩杀、复制技能一致。
- **依据：** 35662 EFFECT_0=20；文案为巨人打击/灭战者与剑刃风暴。破坏者未写入文案，本轮不减 152277。
- **修改：** 继续用 `PowerSpent.Rage`；跳过触发、复制与已处理标记。返怒发生在记录之后。狂暴/防护仍旧路径。
- **待验收：** 不同耗怒减冷却；免费与失败不加减。

### ARMS-04 自动攻击产怒

- **问题：** 过早取整；身经百战 279423 加在所有白字上。
- **依据：** 137049 Aura 213 +300%；262231 EFFECT_1 Aura 213 +10%；279423 Dummy 30 仅暴击。`GetBaseAttackTime` 为未急速武器速度。
- **修改：** 浮点计算；武器战暴击才加身经百战；专精与战争机器仍走 `RewardRage` 的 Aura 213。急速只改变攻击频率。
- **待验收：** 不同武器速度、暴击/非暴击、急速、战争机器、怒气上限。

### ARMS-05 重伤 262304 / 262115 Deep Wounds

- **问题：** 仅破坏者显式上 DoT。
- **依据：** 262304 Aura 42 触发 262115；精通 262111 Aura 108 只修正 262115。不照搬 SimC「顺劈≥3 目标才上重伤」。
- **修改：** 统一 `ApplyArmsDeepWounds`：致死打击、斩杀伤害、压制、巨人打击、灭战者、剑刃风暴周期、破坏者、顺劈、碎颅打击。同一光环刷新，不在脚本里再叠精通。
- **资料缺口：** grill 无 SpellAuraOptions，多施法者叠加以客户端 DB2 为准，未改引擎周期公式。
- **待验收：** 一次有效命中只见一条重伤；精通/急速/暴击跳伤。

### ARMS-06 压制 7384 Overpower / 致死打击 12294 Mortal Strike

- **问题：** 压制脚本仍是巫妖王不懈突击；致死打击无条件移除 7384。
- **依据：** 35662 7384 直伤 + Aura 108 BP 20。
- **修改：** 武器专精在致死打击伤害后再消费 7384；压制命中补重伤与横扫。不懈突击仅在仍有旧光环时保留。
- **待验收：** 压制叠层增伤致死打击后被消费；充能与战术专家恢复。

### ARMS-07 横扫攻击 260708 Sweeping Strikes

- **问题：** 脚本与 SQL 仍是旧 ID，复制会再扣怒。
- **依据：** EFFECT_0 Aura 107 SPELLMOD_JUMP_TARGETS +1；EFFECT_1 Dummy 75。可复制技能见 Family Flags。
- **修改：** 260708 不再打旧额外攻击技能；第二目标 75% 在有脚本的直伤上处理。旧 12328 路径保留。
- **待验收：** 单体技能打到第二目标、不二次扣怒、不递归；断筋等无脚本技能仅靠 JUMP_TARGETS，75% 待确认。

### ARMS-08 猛击 1464 Slam

- **问题：** 空 OnHit。
- **依据：** 35662 伤害在技能数据。
- **修改：** 只加横扫 75% 与第二目标处理。不另写伤害。
- **待验收：** 费用、伤害、战术专家。

### ARMS-09 巨人打击 167105 / 灭战者 262161

- **修改：** 保留原易伤与杀心；补重伤。灭战者不额外扣横扫（范围技能）。
- **待验收：** 增伤时长、灭战者替换巨人打击。

### ARMS-10 旋风斩 1680 / 剑刃风暴 227847

- **问题：** 战斗狂热对每个目标打一次猛击。
- **修改：** OnceMask 每次旋风斩只追加一次猛击。剑刃风暴 50622 补重伤。未改 222634 跳转，需实机核是否仍必要。
- **待验收：** 多目标猛击次数；剑刃风暴跳数。
