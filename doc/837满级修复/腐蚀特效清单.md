# 8.3.7 腐蚀特效清单（细节）

对照：**8.3.7.35662 最终版（含热修）**。底本 `BFA-HavenCore/`。  
本文是「每条效果写到能开工」的总表，不是攻略一句话。单条签名的做法仍在 `做法-A1-无尽之星.md` / `做法-A2-暮光毁灭.md`。

**两套系统，不要混。武器写死效果是第三套，走固定物品，不走 `腐蚀 -` 前缀，也不走 `CorruptionEffects.db2`。**

| 套 | 数据 | 代码家 | 玩家感知 |
|----|------|--------|----------|
| **A 装备好效果** | ItemBonus type 23 → ItemEffect → 驱动技能 | `Item.cpp` 挂光环；战斗在 `spell_corruption.cpp` | 穿上那件腐蚀装就有，和总腐蚀值无关 |
| **B 总腐蚀坏效果** | `CorruptionEffects.db2` **10 行** | `Player::UpdateCorruption()` 已按阈值套/摘光环 | 有效腐蚀 = 装备腐蚀之和 − 抵抗 |
| **C 武器写死** | 尼奥罗萨特定武器的固定 ItemEffect | 同 A 的脚本家，但 bonus 绑在那把武器上 | 净化会去掉；不是随机 `腐蚀 -` 前缀 |

## 怎么读一条

每条尽量有：身份（中文/英文/段数/腐蚀值/bonus/ItemEffect/驱动/外壳）→ 技能链 → 战斗行为 → 数字来自哪个 Dummy → 脚本补什么 / 不要做什么 → Haven 现状 → 第 1 层验收。

外壳（`腐蚀 - xxx 1/2/3`，约 3248xx）多数 **DBC 无光环效果**，只是物品提示名。真装管道走 **ItemEffect 驱动**（315xxx / 318xxx）。`.aura` 打桩打的是驱动或 proc 光环，不是外壳。

`Unknown(285)` 在 SimC dump 里是 8.3 的装等缩放 aura（Haven 侧对应 item-level scaling / `average(item)`）。第 1 层打桩可以先读 Dummy 百分比；真装 2b 再接 ilvl。

## A — 被动（穿上就加属性）

DB2 已是 modifier / 百分比光环。**先不要写 SpellScript**。A0 只看光环在不在、人物面板变不变。多件同效果时数值要叠（SimC 把百分比加到同一个 hidden buff）。

Icy Veins 有几处和 35662 Dummy 不一致，**以 Dummy 为准**。

### 权宜之计 Expedient

- 驱动 315544/315545/315546 Dummy **+6/9/12%** 急速来源；LINKED → hidden **320257**。
- 行为：所有急速来源乘算。无 proc。
- 脚本：不要。验收：`.aura 315544` 急速变。

### 娴熟 Masterful

- 驱动 315529/315530/315531 Dummy **+6/9/12%** 精通来源；LINKED → **320253**。
- Icy Veins 写 8/12/16，那是旧数或误植。35662 是 6/9/12。
- 脚本：不要。

### 多才多艺 Versatile

- 315549/315552/315553 Dummy **+6/9/12%** 全能来源；LINKED → **320259**。
- 脚本：不要。

### 暴戾 Severe

- 315554/315557/315558 Dummy **+6/9/12%** 暴击来源；LINKED → **320261**。
- 脚本：不要。

### 击穿 Strikethrough

- 315277/315281/315282：EFFECT_1 Dummy **2/3/4%** 暴击伤害（aura 285 → hidden **320249** `Modify Crit Damage Done%`）；EFFECT_2 暴击治疗 **+4/6/8%**。
- 文案只提「暴击造成的伤害/治疗 +2/3/4%」。治疗那条 BP 是伤害的两倍，以 SpellInfo 为准。
- 若 320249 的 BP 仍为 0，需要脚本把驱动 Dummy 填进 320249。先 `.aura` 看暴击伤是否变，再决定要不要脚本。

### 闪避者 Avoidant

- 315607/315608/315609 Dummy **8/12/16%**：「闪避 = 急速的 s1%」。MiscValue 指向急速 rating。
- Icy Veins 写 5/8/10，**35662 是 8/12/16**。
- 腐蚀值 Icy Veins 为 10/15/20（旧清单写过 8/12/16，那是把效果数字当成了腐蚀值）。
- 脚本：若核心已实现「闪避随急速百分比」，不要包。否则才补。

### 虹吸者 Siphoner

- 315590/315591/315592 Dummy **吸血 +3/5/8%**。
- Icy Veins 写 2/5/8，**一段是 3%**。
- 脚本：不要（光环是 Leech modifier）。

## B — 总腐蚀坏效果

`UpdateCorruption()`：有效腐蚀 = `CR_CORRUPTION − CR_CORRUPTION_RESISTANCE`。遍历 10 行：`Flags` 含 Disabled 则跳过；低于 `MinCorruption` 或 PlayerCondition 不满足则摘光环，否则 `CastSpell(Aura)`。

**不要重写这个循环。** 缺的是 Aura 挂上之后的战斗脚本。

字段：`ID, MinCorruption (float), Aura (20-bit), PlayerConditionID (2-bit), Flags (2-bit)`。Disabled = `Flags & 1`。PlayerCondition 10 行全是 0。
