# 方案 A — 腐蚀怎么测

**不需要一身满级团本装。** 端里完成度没进游戏测过，用 GM 把「管道」和「单条效果」拆开测。角色建议 120，只为技能和木桩伤害好看，不是为了装。

代码标准：技能 `philosophy.md`「腐蚀」。特效名单：[腐蚀特效清单.md](腐蚀特效清单.md)。

---

## 测之前准备

1. 起 `Repacks/HavenCore`（MySQL 3307 → bnet → world）。
2. GM 号登录 8.3.7.35662。
3. 命令：

```
.gm on
.character level 120
.cheat god on
.cheat cooldown on
```

木桩：`.npc add 31146`（英雄训练假人，没有就 `.lookup creature dummy` / `.lookup creature 假人` 换一个能打的）。站桩前 dist 大约 5 码。

查技能 ID（35662 中文名）：

```
.lookup spell 腐蚀 - 无尽之星
.lookup spell 无尽之星
.lookup spell 彼岸之物
.lookup spell Inescapable
```

把查到的 ID 记进清单，不要抄现役 Wowhead。

## 三层测试（由易到难）

### 第 0 层 — 光环能不能挂上（不测装、不测伤害）

验证：Spell.db2 里有效果技能，服务器肯 `CastSpell`。

```
.aura <腐蚀-无尽之星1 的 spellId>
```

- 自己身上出现光环 → 技能存在，可以开始写/对 SpellScript
- 没光环 / 报 unknown spell → 客户端有名、服务器 Spell.db2 没加载，先查 DataDir 的 Spell.db2，**先不要写脚本**

摘掉：`.unaura <id>` 或 `.unaura all`。

这一层**测不出**「穿装备会不会套腐蚀」。只能测技能在不在。

### 第 1 层 — 效果会不会打（仍不用装）

验证：这条 Aura 的战斗行为（落星、斩击、触须）。木桩选中，自动攻击或对着打技能。

| 要看什么 | 通过 | 失败（Haven 现状，预期） |
|----------|------|--------------------------|
| 无尽之星 | 目标头上落星、奥术伤、可叠易伤 | 光环在，永不触发 |
| 暮光毁灭 | 面前一道斩击 | 光环在，无射线 |
| 虚空回响 | 叠层后对周围崩 | 光环在，无崩 |
| 扭曲的附肢 | 身边出触须抽目标 | 光环在，无召唤 |
| 权宜之计等被动 | 人物面板急速等有变动 | 光环在但属性不变 |

被动属性如果 DB2 光环本身带 modifier，第 1 层就该过，不用脚本。签名效果第 1 层失败是正常的，那是 A1 要写的 SpellScript。

测脚本时仍然用 `.aura`，**先不要做装**。装的问题会和脚本问题缠在一起。

### 第 2 层 — 穿装备走管道（仍不用团本装）

两件事分开做。

**2a 坏效果管道（`UpdateCorruption`）**

需要角色身上有 `ITEM_MOD_CORRUPTION` 数值，不需要那件装真是尼奥罗萨掉落。

做法（按这个顺序试）：

1. `.additem <物品ID> 1 <bonusList>`  
   `additem` 已支持分号分隔的 bonus：`.additem 159627 1 6288;6412`（数字是例子，**bonus ID 要从 35662 `ItemBonus.db2` 查**，查到再写进本文）。
2. 查不到 bonus 时：用 SQL 做一件测试戒指，在 hotfix/`item` 侧加 `ITEM_MOD_CORRUPTION = 25` 和 `= 80` 两档，只放 `sql/updates/`，标注测试用。
3. 不要用 `.modify hp` 冒充腐蚀。没有 `.modify corruption` 就先不要加命令（那是核心，管道通了再说）。

穿上后：

- 人物面板应出现紫色腐蚀
- 有效腐蚀 ≥1 应挂上 Grasping 一类（DB2 第一档）
- 再穿高腐蚀测试装或叠多件，看 20/40 档眼睛、彼岸之物
- 脱掉，光环应掉

**2a 通过 = 清单 B 的管道可用。** 与无限之星好不好使无关。

**2b 好效果在装备上**

需要 bonus 带 `ITEM_BONUS_ITEM_EFFECT_ID`（type 23），指向「腐蚀 - 无尽之星 1」那个 ItemEffect。

- `.additem` 加上对应 bonus list（从 `ItemBonus.db2` / `ItemEffect.db2` 对）
- 或 8.3 的「保存的污染物」一类道具（像附魔一样往未腐蚀物品上刷效果），若物品和法术在 35662 里存在也可以

穿上：应同时有（1）腐蚀值（2）`腐蚀 - 无尽之星` 光环。脱下都掉。

**2b 没通不要阻塞 A1。** A1 用第 1 层 `.aura` 就能写脚本、看落星。2b 是「像正式服一样从装备来」。

| 项 | 建议 |

## 一次进游戏的最短路径（今天就可以做）

1. 120 GM，木桩。
2. `.lookup spell 腐蚀 - 无尽之星`，记下三段 ID。
3. `.aura` 第一段，看光环。
4. 打木桩 30 秒，看有没有星。**预期：没有。** 记进进度表：「第 1 层无尽之星不触发」。
5. `.unaura`，换 `.aura` 权宜之计 1，看急速变不变。
6. `.lookup spell 彼岸之物`，先不 aura（那是怪）。改查坏效果光环名；没有就把有效腐蚀的测试留到 2a。
7. 下线，把查到的 spellId 填进 [腐蚀特效清单.md](腐蚀特效清单.md)。

这 7 步结束 = 完成度「进过游戏的腐蚀基线」，不是修复完成。

## 修完一条签名效果后怎么验收

以无尽之星为例：

1. 第 1 层：`.aura` 一段，打木桩，能看见落星和伤害；`.unaura` 立刻停。
2. 二段、三段用同一个脚本、不同 Aura ID（或同一 Aura 不同 BP），伤害/次数应更强，不要复制三份逻辑。
3. 第 2b（有 bonus 之后）：穿测试装自动获得光环，不用 `.aura`；脱掉消失。
4. 进度表写：进了游戏、用了 `.aura` 还是真装。

坏效果 2a 单独验收，不要和落星绑在同一次 PR。
