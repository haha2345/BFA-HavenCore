## 怎么测（A4 / 木桩）

1. 重启世界服（缩放在刷怪时写入，只 reload 不够）。
2. `.gm on` + `.labtentacle`：挂 316815，卸星 / 暮光 / 回响。
3. 团本桩：`.labaoe`（31146）。CLEU 鞭笞应约 **2379 / 3568**，猛击约 **6188**。
4. 对照桩：`.labdummy`（190001，无缩放、真掉血）。CLEU 目标名必须是 HavenLab无缩放桩。
5. 正场普通桩（伯拉勒斯 / 达萨罗，模板 120）：法术 CLEU 仍应是公式，物理不再按 +3 护甲。
6. 新手 1–63 桩：CLEU **仍应被压**。
