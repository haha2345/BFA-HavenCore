# A3 虚空回响 — 正确做法与思路

对照：8.3.7.35662（含热修，见 [设计-腐蚀-Blizzlike.md](设计-腐蚀-Blizzlike.md)）。  
家：`BFA-HavenCore/src/server/scripts/Spells/spell_corruption.cpp`。  
第 1 层打桩：`.labecho` / `.aura 317014`。真装 318280 / ItemEffect **未做**。

本文只记**现在认定正确的做法和为什么这样选**。不记试错。

---

## 这份文档对齐的需求

1. 第 1 层能稳定复现：有 GCD 的伤害技能叠层；平砍 / 无 GCD 技能不叠；叠层时有几率坍缩；坍缩后对周围每秒暗影伤，跳数 = 坍缩时的层数，层数往下掉。
2. 和好效果 / 坏效果两套管对齐：不进 `UpdateCorruption()`，不改 opcode / 核心施法。
3. 抄 A1/A2 的家、数据源、脚本层、验收；不把回响做成特例核心。
4. 测试可以靠 HavenLab，战斗脚本不能依赖插件才能工作。

## 官方行为（第 1 层要看见的）

1. **叠层：** 有 GCD 的伤害技能（黄字近战/远程、敌对法术）每次成功打出 → 自己 +1 层 317020。平砍、无 GCD、治疗、DoT 跳、回响自己的 317029：**不叠**。
2. **坍缩判定：** 身上**已经有层**时，每次本该叠层的 proc 先掷 `ECHOING_VOID_COLLAPSE_CHANCE`。中了就开坍缩、**不再 +1**；没中就 +1。0 层时只叠、不掷。
3. **坍缩中：** 对周围 15 码敌对每秒一跳 317029，跳数 = 开坍缩时的层数。每跳扣 1 层。层到 0 停。这段时间 317014 **不再叠层**（SimC 会 deactivate callback，避免最后一跳又叠回去）。
4. **伤害：** `maxHP × (段 Dummy / 100) %`。一段 0.4%。每目标独立暴击。会拉未进战的怪。
5. **第一跳：** SimC `immediately pulses`。DBC 周期 1 秒、默认时长 2 秒。实现：若 317022 没有「apply 立刻跳」，`OnApply` 打第一跳；时长改成 `层数 × 周期`（可加半秒余量）。同一毫秒不要打两跳。

## 正确实现

代码：`spell_corruption.cpp`（往里加，不新建目录）。  
SQL：`sql/updates/world/YYYY_MM_DD_NN_world_corruption_echoing_void.sql`  
  - `spell_script_names`：317014 / 317029（317022 只在「必须改时长 / 第一跳」时才挂，且脚本第一行检查 317014）。  
  - `spell_proc`：**只**给 317014 补 ProcFlags。  
注册：已有 `AddSC_corruption_spell_scripts()`。

### 为什么这里可以写 `spell_proc`（和 A1 不矛盾）

35662 的 317014 热修后 `ProcFlags = 0`。`OnProc` 永远不会进。  
热修前掩码是 **69904 (0x11110)**：

```
PROC_FLAG_DONE_SPELL_MELEE_DMG_CLASS      0x00000010
PROC_FLAG_DONE_SPELL_RANGED_DMG_CLASS     0x00000100
PROC_FLAG_DONE_SPELL_NONE_DMG_CLASS_NEG   0x00001000
PROC_FLAG_DONE_SPELL_MAGIC_DMG_CLASS_NEG  0x00010000
```

黄字近战 + 黄字远程 + 敌对 generic + 敌对魔法。**没有**白字平砍（0x4）、**没有**周期（0x40000）。暮光的 69908 = 69904 + 白字。

`spell_proc` 的职责是把这条热修前的技能掩码 + 700ms ICD + Chance 101 补回去，**不是**把平砍加进去。GCD 过滤 DBC 表达不了，留在 C++。

### 入口

| 技能 | 脚本 | 做什么 |
|------|------|--------|
| 317014 | AuraScript `OnProc` | `PreventDefaultAction()`。无 GCD / 正在坍缩 / 非法目标：返回。否则掷坍缩或 +1 层 317020 |
| 317022 | 仅当需要改时长 / 第一跳 | **仅当** `GetCaster()->HasAura(317014)`。否则立刻返回，把光环留给虫巢思维 |
| 317029 | SpellScript `OnHit` | **仅当**施法者有 317014（或段光环）。`SetHitDamage(maxHP × pct)`；扣 1 层；层 0 则摘 317022。无 317014：不动伤害（王技能） |

施法处禁止裸数字，一律 `enum EchoingVoidSpells`。

### `HandleEchoingVoidProc`（唯一叠层/坍缩函数）

1. `GetProcSpell()` 为空，或 `GetSpellInfo()` 的 GCD / `StartRecoveryTime` 为 0：返回（热修：无 GCD 不叠）。平砍通常没有 proc spell，也会在这里被挡。
2. 已有 317022：返回（坍缩中不叠）。
3. 已有 317020 且 `roll(ECHOING_VOID_COLLAPSE_CHANCE)`：`StartEchoingVoidCollapse(caster)`，返回。
4. 否则对施法者 `CastSpell(317020, triggered)`（叠层）。层上限读 317020 `StackAmount`（99）。

### `StartEchoingVoidCollapse`

1. 层数 = 317020 的 `GetStackAmount()`，至少 1。
2. 对施法者放 317022（triggered）。有 317014 的 AuraScript 把时长改成 `层数 × 317022 EFFECT_0 周期`。
3. 第一跳：见上「第一跳」。
4. 每跳 317029：填伤、扣层。AoE 过滤 `_IsValidAttackTarget`（会拉怪）。

### 伤害

```
rank = 318486 → 1.0%；318485 → 0.6%；其余（含裸 317014）→ 318280 的 0.4%
damage = maxHP × (rank EFFECT_0 BasePoints / 100) / 100
```

SimC：`effectN(1).percent() / 100`（`percent()` 已是 BP/100）。一段 40 → 0.4% 生命。  
只 `SetHitDamage` / `SPELLVALUE_BASE_POINT0`。半径读 317029 `CalcRadius()`（15）。

真装 318280 的 `average(item)` **还没接**。接的时候只改数字来源，不动叠层 / 坍缩 / GCD 过滤。

### 不要做

- 不要给 317257 那种「星」写 `spell_proc` 去加平砍；回响这条 `spell_proc` 只复原 69904。
- 不要把 15% 写成「官方 DBC」。
- 不要无条件脚本 317022 / 317029（会改虫巢思维）。
- 不要坍缩中继续叠层。
- 不要用平行 C++ 计时器替代 317022 周期（和 A2 删扫描事件同一原则：判定跟官方物体走）。
- 不要把回响写进 `UpdateCorruption()`。

## 怎么验收（第 1 层）

`.gm on` + `.labecho`（卸星/暮光，给自己 317014）+ 木桩：

- 平砍：317020 不上。
- 猛击等有 GCD 黄字：`ECHO_STACK`，自己身上 317020 层数 +1。
- 无 GCD 技能（若当前专精有）：不叠。
- 旋风斩打到多名：只叠 **1** 层（按施法 proc，不按命中次数）。
- 坍缩：`ECHO_COLLAPSE stacks=N`，随后约 N 次 `ECHO_TICK` / 317029 暗影，15 码内桩都挨打，层数每秒 -1，到 0 停。
- 一段伤害约等于最大生命 × 0.4%，可暴击；战报一条、不双倍。
- 坍缩期间再猛击：层数不涨。
- 未进战的野怪在 15 码内：挨打并冲过来（拉怪 = 正确）。
- 平均坍缩层数先记下来（对照 15% 模型）；明显长期 2 层或 20 层再改常量。

真装 bonus `6549/6550/6551` 未接。

P1（2026-08-27）：`HandleEchoingVoidProc` 滤 `StartRecoveryTime==0`（平砍 / 无 GCD 不叠）。echo pack 已写「无 GCD 叠层 = 过滤失效」。**待进游戏验收**：无 GCD 技能不叠；坍缩拉野怪写进测试记录。

## 和哲学对一下

- 两套腐蚀没混。回响不碰坏效果表。
- 没改施法核心。`spell_proc` 是数据层补热修清零的掩码，和 A1「不要用 spell_proc 改星的白字」不冲突。
- 317022/317029 与虫巢思维共用 ID：用 317014 当钥匙，邻居王技能不吃玩家伤害公式。
- 家仍在 `spell_corruption.cpp` + `spell_script_names`。
