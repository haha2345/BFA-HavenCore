# 腐蚀系统 Blizzard-like 设计（总纲）

对照版本：**8.3.7.35662 最终版（含全部热修）**。底本 `BFA-HavenCore/`。
本文回答「整个腐蚀系统做成什么样才算 blizz-like」，单条效果的做法在各自的 `做法-Ax-*.md`。

2026-08-26 定的四个需求决定：

1. AT 类效果的命中判定走 **AreaTrigger 本体**（OnUnitEnter / 样条位置），不另写平行的 C++ 扫描。
2. 光柱、触须等**扫到就打，会拉动未进战的怪**——和正式服一致，不做私服式防拉怪保护。
3. 数值对齐 **8.3.7 最终版 = 含热修**。热修值（如暮光 10 目标上限）DBC 里没有，允许作为署名常量写进 C++，注释标明热修日期。
4. 本文覆盖全盘：好效果管道、坏效果阈值、真装 ItemEffect、ilvl 缩放。

---

## 总架构：两套系统，三层管道

```
┌─ A 装备好效果（ItemEffect）────────────────────────────┐
│ 物品 Bonus type 23 → ItemEffect → 外壳光环(324889…)     │
│   → 隐藏驱动(318274…) → proc 光环 → 战斗行为脚本         │
│ 家：Item.cpp 挂光环；scripts/Spells/spell_corruption.cpp │
└─────────────────────────────────────────────────────────┘
┌─ B 总腐蚀坏效果（CorruptionEffects.db2 10 行）──────────┐
│ 有效腐蚀 = CR_CORRUPTION − 抵抗 → 过阈值套光环           │
│ 家：Player::UpdateCorruption()，已能跑，不重写            │
└─────────────────────────────────────────────────────────┘
┌─ C 坏效果的战斗行为（阈值光环挂上之后干什么）────────────┐
│ 触须减速、腐蚀之眼、彼岸之物…同样进 spell_corruption.cpp  │
└─────────────────────────────────────────────────────────┘
```

铁律（沿 A1 的哲学，不变）：

- 两套不混。签名效果脚本禁止 `if (corruption >= 20)`；坏效果不碰 ItemEffect。
- 数据能表达的不写 C++：proc 掩码、RPPM、层数、半径、时长全信 35662 DB2。
- 脚本只补两类东西：**DBC 里 BP=0 的伤害**、**数据表达不了的行为**（落星延迟、AT 命中结算、热修值）。
- 不改施法核心、不搬 opcode。核心（`src/server/game/`）只修**真 bug**（例：AreaTrigger `OnRemove()` 双调用），修完对邻居系统无感。

## 伤害结算的统一形状

所有腐蚀伤害技能（317265 / 317159 / 317029 / 316835）遵守：

- 直伤只走 `SetHitDamage` / `SPELLVALUE_BASE_POINT0`；周期伤（316835）走 `DoEffectCalcAmount`。让 school-damage / periodic 自己结算（暴击/全能/易伤走核心管线）。**禁止再叠 `DealDamage`**——A1 曾双倍扣血，已修（2026-08-26）。
- AT / 延迟事件跨帧传值只用 GUID + 显式传伤害（CastCustomSpell BP0），不存裸指针。
- 每目标独立暴击；不做「腐蚀伤害不暴击」之类的臆测限制。

## A 好效果：按实现形状分三类

| 类 | 例子 | 做法 |
|----|------|------|
| 纯属性被动 | 权宜之计、娴熟、暴戾、虹吸者… | DB2 光环是 MOD_RATING 系就**零脚本**；A0 验光环在不在即可 |
| 次级属性触发 | 致命之势、急速脉搏、磨砺心灵… | proc 光环 DB2 驱动；脚本最多补层数/触发行为 |
| 签名（战斗行为） | 无尽之星、暮光毁灭、虚空回响、扭曲的附肢、虚空仪式 | 每条一个 `做法-Ax` 文档 + AuraScript/SpellScript/AreaTriggerAI |

签名效果全部收进 `spell_corruption.cpp` + `spell_script_names`，不建「腐蚀管理器」。

## 真装管道（2b，签名效果打桩完后做一次）

目标：穿上腐蚀装 → 好效果自动出现并按 ilvl 缩放；脱掉 → 消失；总腐蚀值同步变化带动坏效果。

1. **挂光环**：`Item.cpp` 的 `ITEM_BONUS_ITEM_EFFECT_ID`(23) 已有管道，验证外壳（324889 系）会 ON_EQUIP 挂上/摘掉。缺口在哪补哪，不重写。
2. **外壳 → 驱动**：外壳 DBC 无光环效果（A1 已证实），由 SpellScript 把隐藏驱动（318274 系）接上——这一步已在 A1 用 AfterCast 做了第 1 层，真装层改为随装备 Apply/Remove。
3. **ilvl 缩放**：318274 系伤害是 `$s2/100 * $max($AP,$SP)` 里的百分比 + `average(item)` 装等基数。接的时候只改伤害数字来源（读 aura 285 / RandPropPoints 曲线），**不动 proc/落点/延迟**。
4. **腐蚀值**：`ITEM_MOD_CORRUPTION` → `UpdateCorruption()` 已接。验收：穿三件 25 腐蚀装 = 总 75，眼睛/触须按阈值出。

## B 坏效果：对齐官方阈值行为

`UpdateCorruption()` 的循环和 10 行表不动；缺的是**行为脚本**（C 层）：

| 阈值 | 效果 | 行为要点（blizz-like） |
|------|------|------------------------|
| 1+ | 蔓生触须 Grasping Tendrils | 受伤有几率减速，幅度随腐蚀升 |
| 20+ | 腐蚀之眼 Eye of Corruption | 出眼，站近了持续暗影伤 |
| 40+ | 宏伟妄想 Grand Delusions | 彼岸之物追击，**碰到才结算**（同样走 AT/单位真身，不做假判定） |
| 60+ | 层叠灾难 Cascading Disaster | 被彼岸之物碰到立刻加触须+眼 |
| 80+ | 不可避免的厄运 Inevitable Doom | 受伤放大、受疗减少 |

顺序在签名效果（A1–A4）之后、真装（2b）之前或并行，一次一条，各自竖切验收。

## 边界（明确不做）

- 惊魂幻象、黑帝国披风及其抵抗成长、恩佐斯突袭
- 尼奥罗萨武器固定效果（吞噬活力等）
- Heart of Darkness 特质
- 12x 核心的任何搬运

## 验收（系统级，替代各条效果自己的验收之上）

- [ ] 穿/脱腐蚀装：好效果光环随装备上下，无重启
- [ ] 同一角色好坏效果并存互不干扰（穿 75 腐蚀：出星 + 出眼）
- [ ] 抵抗升高后低于 MinCorruption 的坏效果掉
- [ ] AT 类效果：判定与视觉同源（关掉视觉包判定仍准；判定不超前/滞后于光束）
- [ ] 光柱/触须会拉未进战的怪（blizz-like，写进测试步骤而不是当 bug 报）
