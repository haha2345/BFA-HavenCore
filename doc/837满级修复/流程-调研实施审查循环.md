## 相对上一版改了什么

你补充了「先分类再深挖、按难易派人、架构与分模块方案、做完再接线复核」。下面几条是讨论后收进技能里的约束，避免流程自己把自己拖死。

1. **分类和效果调研必须分开。** 不知道要修哪些时，先出 `分类-<系统>.md`（两轮审查），你点头后再按原子搜 DB2 和论坛。混在一轮会又切又查数字，注意力立刻散掉。
2. **原子功能有定义，难度只决定顺序和派人，不构成无限切分。** 原子 = 能单独进游戏验收的一条竖切。切到函数级会让审查次数爆炸。
3. **效果调研的 3 轮按波次，不按原子相乘。** 十个原子各跑三轮审查不现实。R1 最多 4 路并行；R2 一个人审本波全部；R3 只打问题清单。
4. **其他版本核心不是 8.3 真相。** 打开 `12x_Core` 等目录之前必须读 [00-总览与结论.md](../../../doc/4x-7x-开源端对837修复参考/00-总览与结论.md)。12x 只许看写法；AshamaneBFA / Boralus / MTT 多数是空壳或 SQL。8.3 腐蚀和尼奥罗萨没有第二套更满的开源战斗实现。
5. **Haven 现有代码抄形状，对错听 35662。** 服务端现在能跑不等于对。
6. **「文件在」不等于「架构在」。** 跳过架构设计的条件是管道真的在跑（调用点、BP 非全 0、loader 调用了）。空 `boss_*.cpp` 仍要先定家。
7. **客户端提示是方案里的交付物，不是实施完再补。** 每个模块方案必须写 `.lab` / HavenLab / 人测。阶段 4 只检查有没有漏接，不再发明新机制。
8. **分类表要给你看一眼；其余未决打包到深挖结束再问。** 切错最贵。数字拿不准不打断每一条。
9. **已经点名原子功能时走快路径**，跳过阶段 0。
10. **客户端与 CASC 在流程里是一等公民。** 游戏目录 `client/World of Warcraft`，已抽数据 `Repacks/XYWOWT837/Data`（DB2 在 `dbc/zhCN`）。缺表用 `mapextractor -e 2` 按需从 CASC 抽到 `_tmp_db2`，不抽全量 maps、不写 C 盘。网页被反爬就开 Cursor 浏览器。能打开的 db2、日志、SavedVariables 必须打开，禁止「查不到」直接停。细节：`.grok/skills/837-fix-loop/references/access.md`。

## 五阶段（完整路径）

该表格用来对照「从不知道要修什么」到「代码接上客户端、可以进游戏验收」的完整顺序。

| 阶段 | 落盘 | 审查 | 你出场 |
|------|------|------|--------|
| 0 分类 | `分类-<系统>.md` | 2 轮 | 表定稿时看一眼 |
| 1 按类深挖 | `调研-*.md`、`细节-F*.md` | 3 轮/波次 | 未决打包确认 |
| 2 架构（可省）+ 总纲 + 模块方案 | `设计-*-架构.md`、`方案-<系统>.md`、`方案-<系统>-<模块>.md` | 各 2 轮 | 要动 `game/` 核心时拍板 |
| 3 实施 | 代码 / SQL / HavenLab | 每 Task 2–3 轮 | 不阻塞；进游戏仍归你 |
| 4 集成复核 | `复核-<系统>.md` | 1 轮 | 按验收步骤进游戏 |

快路径：你已经知道原子（例如「暮光十目标」）→ 从阶段 1 或已有调研进阶段 2。

## 历史上的目标模式提示词仍有效的部分

必读文档、铁律、写码串行、独立审查、增量编译、HavenLab 镜像、你进游戏 Agent 不阻塞——这些从腐蚀剩余修复 / 尼奥罗萨武器 / 掉落段位三次提示词里来，没有推翻。

## 推荐用法

1. 整条流水线：复制 `prompts.md` 总控，或说按 `/837-fix-loop` 跑。
2. 只做其中一步：直接点名 `/837-fix-classify`、`/837-fix-research`、`/837-fix-plan`、`/837-fix-implement`、`/837-fix-integrate`。
3. 长跑用 `/goal` 贴同一段总控。
4. 你只在：分类表、深挖未决、动核心、同一 Task 三轮不过、进游戏验收，这五处拍板。

进度账本：`doc/837满级修复/进度-<系统>.md`。
