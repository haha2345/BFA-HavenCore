6. 活动期间 events 在 CASTING 检查前推进；每帧最多消费一次 launch，等待事件至多一个；迟到按真实 start 重锚，不补发积压。空候选或入口返回 false 丢本轮，只保留下一次 8 秒机会；这是保守失败策略，不冒称历史空目标规律。

8. `OnSpellFinished(SpellInfo const*)` 没有成功参数，且在清 CASTING/判断 ok 前回调；不得用它作成功信号、排下一酒或安排 apply。
9. 共同 Stop 顺序固定：先 `brewStarted=false`，再 `events.Reset()`，最后按三个发起 ID 分别 `InterruptNonMeleeSpells(true, brewId, true)`。Stop 幂等，不清通用 Unit 事件，不取消邻居技能；同步 finish 不得复活队列。
10. Rummy Reset、船长 Reset/evade/home 与实际非 IN_PROGRESS 状态均承担同步 Stop；evade 在早退前停止，仍 IN_PROGRESS 时同步请求 FAIL；controller 原 DONE 判死条件保留。UpdateAI 状态检查仅兜底，不能等下一帧取消 SpellEvent。
