### 256056 成功钩子（写死这一条，不要并列候选）

仓库里**没有** `OnSpellCast`。核对结果：

| 符号 | 在哪 | 本 Task 是否使用 |
|------|------|------------------|
| `OnSpellCast` | **不存在**于 `CreatureAI` / `BossAI` / `ScriptedCreature.h` / `UnitAI.h`。玩家侧是 `PlayerScript::OnSuccessfulSpellCast(Player*, Spell*)` | **禁止写** |
| `OnSpellCasted(SpellInfo const*)` | `CreatureAI.h` 约 263 行。`Spell.cpp` 约 3443 行在 `Spell::finish` 里、`handle_immediate()`（含效果 28 召唤）之后调用 | **用这个** 听 256056 成功 |
| `OnSuccessfulSpellCast(SpellInfo const*)` | `CreatureAI.h` 约 291 行。同一 `finish()` 稍后约 3496 行再调一次 | **禁止再 override**（与 `OnSpellCasted` 叠会二次 `ExitVehicle`） |
| `SpellHit` | `CreatureAI.h` 约 251 行 / `ScriptedCreature.h` 约 184 行：自己**被打中** | 方向反了，禁止用来切阶段 |
| `IsSummonedBy` | `UnitAI.h` 约 164 行 / `CreatureAI.h` 约 232 行。`npc_sharkbait` **没有** override | Reset 开战前就会召唤 126841，开战就会走这条，**不是** 75% 锚点 |

`boss_skycap_kragg` 继承 `BossAI` → `ScriptedAI` → `CreatureAI`。`ScriptedCreature.h` / `BossAI` **没有**声明 `OnSpellCasted`，直接 override 基类即可。现有文件已 `#include "SpellInfo.h"`，已有 `OnSpellCastInterrupt`（打断回春酒），本钩子写在旁边。

**唯一路径：**

1. `DamageTaken`：75% 且 `phase == PhaseMount` 时 `phase = PhaseUnmount`，`Talk(TalkUnmount)`，**只** `me->CastSpell(me, KraggSpells::SpawnParrot, false)`。**不要**在这里 `ExitVehicle`、不要在这里 `MovePoint`、不要在这里 `ScheduleEvent` 二阶段。
2. `void OnSpellCasted(SpellInfo const* spellInfo) override`：仅当 `spellInfo->Id == KraggSpells::SpawnParrot` 时：`me->ExitVehicle()`；对 `Reset` 已有的那只 126841 `MovePoint(MovementPointMiddle, MiddlePos)`；`events.Reset()`；再排 `EventAzeritePowderShot` 2000 与 `EventRevitalizingBrew` 15000。这是下坐骑与鸟起飞的**唯一**地点。
3. `spell_spawn_parrot`：`OnEffectHit` 对效果 28（召唤），若 `GetGuidData(NpcSharkBaitBoss)` 已有生物则 `PreventHitDefaultEffect`。**只**防第二只鸟，不在这里 `ExitVehicle`。`Reset` 开战前已有 126841，所以这条 SpellScript **必须写**，不是可选项。`spell_script_names` 插入 `(256056, 'spell_spawn_parrot')`。
