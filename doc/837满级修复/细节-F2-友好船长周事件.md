### 2.2 C++ 怎么写才不算发明 ID

`instance_freehold.cpp` 在 `struct instance_free_hold` 上实现成员 `GetActiveFreeholdCrewWeek() const`，经 `freehold.h` 的自由函数 `GetActiveFreeholdCrewWeek(InstanceScript const*)` 给其它 cpp 调用（见第 5 节，照抄能编）。返回本文件的帮派枚举，**不要**在调用点散落三个自造数字：

```cpp
enum FreeholdCrewWeek : uint32
{
    CrewWeekNone = 0,
    CrewWeekCutwater = 1,    // 破浪 → 乔里
    CrewWeekBlacktooth = 2,  // 黑齿 → 劳尔
    CrewWeekBilgeRats = 3    // 水鼠 → 尤朵拉
};
```

函数体在 dump 搜到之前**不许**写成 `IsActiveEvent(209)` / `210` / `211`。搜到后再把「表名 + ID → 上述枚举」填进 **成员** `instance_free_hold::GetActiveFreeholdCrewWeek()` 这一个函数（不要在 gossip 调用点散落 ID）。`enum FreeholdCrewWeek` 只定义在 `freehold.h` 一次，本节代码块与第 5.1 节是同一份，禁止在 cpp 再定义一份。同一时刻只应有一种帮派为真；三种都假视为未做事件：三人全敌对。禁止 `GetGameTime()/604800 % 3`。

GM 验收：用搜到的 ID 做 `.event start`（或对应 worldstate 命令）。**禁止**方案或验收清单写 `.event start 209/210/211` 当作正式手续。

开服评论「第一周拉乌尔、第二周狐人喝酒」以及 2018-08-14 起 21 天循环：只能在**用户确认可以新建 `game_event` 行**之后，才作为 `start_time` / `occurence=30240` / `length=10080` 的填写参考。在此之前不要把这套日历写进 SQL。

## 5. Instance 接口（与 Task 2 同一套 Data；不是落盘）

`SetData` / `GetData` 只写在当前副本脚本对象的内存里。基类 `GetSaveData` 只写 Headers + 四个 BossState；`WriteSaveDataMore` 默认空。**本阶段不要** override `WriteSaveDataMore` / `ReadSaveDataMore` 把入伙塞进 `instance` 存档。

含义：

- **同一副本会话**（实例对象还在）：玩家掉线再进，`OnPlayerEnter` 读 `GetData` 再 `DoAction`，船长阵营能恢复。
- **会话结束**（全员离开导致卸载、世界服务器重启、实例过期后再进）：入伙丢失，船长回到敌对，须重做当周事件。进游戏验收这一条，不要写成「已经落盘」。

### 5.1 跨文件怎么调用（照抄能编；禁止猜）

`struct instance_free_hold` **只定义在** `instance_freehold.cpp`，不要搬进头文件。**不要**改 `InstanceScript.h` 加虚函数。事件 / gossip 脚本在 `boss_council_o_captains.cpp`（**不要**放 `freehold.cpp`，`AddSC_freehold()` 保持空）。

`freehold.h` 声明（enum 只一次）：

```cpp
class InstanceScript;

enum FreeholdCrewWeek : uint32
{
    CrewWeekNone = 0,
    CrewWeekCutwater = 1,
    CrewWeekBlacktooth = 2,
    CrewWeekBilgeRats = 3
};

FreeholdCrewWeek GetActiveFreeholdCrewWeek(InstanceScript const* instance);
void NotifyCrewEventComplete(InstanceScript* instance, uint32 captainEntry);
```

`instance_freehold.cpp`：struct 上实现无 `InstanceScript*` 参数的成员；同一 cpp 用 `dynamic_cast<instance_free_hold*>` 包成上面两条自由函数。调用点**不要**自己 cast，照抄：

```cpp
if (GetActiveFreeholdCrewWeek(me->GetInstanceScript()) != CrewWeekBilgeRats)
    return;
NotifyCrewEventComplete(me->GetInstanceScript(), uint32(FreeholdCreature::NpcCaptainEudora));
```

成员 `NotifyCrewEventComplete(uint32 captainEntry)` 必须按这个顺序：

1. `SetData(DataCrewEventDone, 1)`。
2. `SetData(DataFriendlyCaptain, captainEntry)`（126845 或 126847 或 126848）。
3. 对三船长 `DoAction`：匹配 entry 的走对应 `ActionSelectCaptain*`，把该船长 `SetFaction(2580)` 并 `checkFaction()` 摘掉 257821。
4. 将该帮小怪 entry 列表里、本图 200 码内生物改成阵营 2580。这是「入伙后谁变友好」，不是周公式：

| 帮派 | entry |
|------|--------|
| 破浪 | 129559、129599、129601、126845 |
| 黑齿 | 129548、129529、129547、126847 |
| 水鼠 | 129550、129527、129600、129526、126848 |

不要在入伙时把另外两帮小怪改友好。不要在议会 DONE 后撤离该帮（那是 10.1）。

`OnPlayerEnter`：议会未 DONE 且 `GetData(DataCrewEventDone)` 非 0，则按 `GetData(DataFriendlyCaptain)` 再 `DoAction` 一次。议会是否结束用 `GetBossState`，见 F5。

`boss_council_captain::DoAction` 必须能处理三条 Action，不能只处理劳尔。
