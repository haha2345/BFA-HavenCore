# 功能 8 细节：用污染物给装备添加腐蚀

对照 **8.3.7.35662**。设计正文：[2026-08-30-mother-purify-ilvl-design.md](../../docs/superpowers/specs/2026-08-30-mother-purify-ilvl-design.md)。  
买瓶子是功能 5。本文件只回答：**使用时写哪些加成、拒绝什么目标**。

## 1. 正式服规则

暴雪新闻与 5 月蓝帖：污染物像附魔一样，打在 **尚未腐蚀、但本来就可以被腐蚀** 的物品上，并带上对应腐蚀惩罚。已腐蚀件必须先泰坦净化。

2020-05-20：第四赛季制造装可以打，工程护目镜（艾泽里特）和炼金石（饰品）除外；制造产出时仍不会随机出腐蚀。  
2020-05-21：热修前已经净化过的装备也可以打。  
35662 按上述热修之后的规则。

不能原地升段：35662 没有「把 6552 换成 6554」的第三条法术。要换段，先净化再打另一瓶。

不能打尼奥罗萨 **独特** 武器特效（列表 6567–6572）。商店 52 瓶子树没有一条指向它们。毁灭时分那种 **非独特** 签名（暮光三段 6539）可以当普通污染物买到。

## 2. 法术效果 223

本核：`SPELL_EFFECT_CHANGE_ITEM_BONUSES = 223`，`SpellEffects.cpp` 仍是 `EffectNULL`。

52 瓶的使用法术都是：效果 223；`MiscValue_0` = 树 **2821**（子列表 **6516**，空列表，功能 4 已从随机池剔除）；`MiscValue_1` = 该瓶特效树。另有一个效果类型 5、杂项全 0，当作客户端「对物品使用」占位，不是加成载荷。

目标：像附魔一样，法术需要物品目标（`m_targets` 中的物品）。`SpellInfo.cpp` 里效果 223 目前是 `EFFECT_IMPLICIT_TARGET_NONE`。实现效果函数时从物品目标读取；若 324889 的法术属性本身带物品目标标志，不要另造目标类型。

经验冻结的语义：展开 `MiscValue_1` 树上全部非空子列表并追加；不要把 6516 写进装备；若目标已有腐蚀列表则失败。

被动树会挂两条：效果列表 + 点数列表。必须 `VisitItemBonusTree`（或等价）收集全部子列表，不要只取第一个 `ChildItemBonusListID`。

## 4. 拒绝条件（服务器必须查）

1. 目标不是玩家拥有的装备物品。
2. `ItemAlreadyHasCorruptionEffect` 为真（已腐蚀）。
3. 艾泽里特赋能护甲、艾泽拉斯之心、饰品、炼金石、工程护目镜、传说披风阿什吉拉卡马斯（物品 **169223**；不要把所有披风都拒掉）。
4. 展开结果若包含 6567–6572（不应发生；若数据被改过则仍拒绝）。写死武器仍挂独有效果时也不能再叠商店腐蚀。
5. 目标物品等级 / 赛季管道明显不是第四赛季可腐蚀装（沿用功能 4 资格，不要发明「物品等级低于 400 就不能打」除非 ClientData 有依据）。从未出过腐蚀的赛季 4 件 **可以** 涂；「必须曾经出过腐蚀」是论坛误解。2020-05-28 之后评级 PvP 周常装也可以涂。

客户端若仍允许对准已腐蚀件，以服务器拒绝为准。`C_Item.IsItemCorruptable` 是客户端 C API，参数是某一格里的**实例**，不是模板编号；服务器不能指望客户端替你拦。已装备栏能否作为法术目标，没有单独蓝帖；附魔通常可以点人物面板。经验冻结：背包与已装备槽都允许，与附魔一致。不要把泰坦净化的物品交互框拿来当「涂抹框」。加成组 **158** 是掉落目录，不是商店价签。

## 5. 与 `Item::AddBonusList` 的关系

追加列表后必须走现有 `AddBonusList` 刷新 `_bonusData` 和法术充能。不要对已有实例直接 `SetBonuses` 而不先 Initialize（会叠状态）。不要 `ClearBonuses()`。穿着时走 `_ApplyItemMods`，与净化相同。

Wago：污染物堆叠与上限为 1。买一瓶用一瓶。ItemEffect 的 Charges 为 −1 表示该效果行不是「有限次数充能」，仍应消耗这件消耗品本身。

## 6. 挖出的恩佐斯之眼（不要并进本功能）

物品 174876，法术 316985，拉希奥（155496）用 **25000** 枚货币 1719 出售。给棱彩镶孔，不是腐蚀特效。2020-05-28 热修曾把它和污染物一起扩大到评级 PvP 周常装。本阶段不做镶孔商店。

## 7. 本核缺口

- 效果 223 空实现。
- 没有「目标已腐蚀则失败」的使用脚本（有了 223 之后应做在效果函数里，不要 52 个 SpellScript）。
- `.labgear` 已能手写加成，不能代替本功能。

## 8. 验收

进游戏操作勾选见 [验收-玛乌尔净化装等污染物.md](验收-玛乌尔净化装等污染物.md) 第 5 节。摘要：

- 白板胸甲使用 177983：实例出现 6552，穿上有无尽之星一段。idTip 可见 `BonusID:`。SimulationCraft 导出应出现 `bonus_id=6552`（被动件例如权宜之计一段应是 `bonus_id=6474/6455`）。客户端 `IsCorruptedItem` 为真后，CorruptionTooltips 应从链接里的 6552 认出 Infinite Stars I。
- 同一件再使用 177985：失败，6552 不被 6554 覆盖。
- 先净化再使用 177985：成功，变为 6554。
- 对饰品、艾泽里特、已带 6567 的 An'zig Vra、戒指涂吞噬活力、169223 披风：失败。
- 权宜之计一段：同时有 6474 与 6455。Pawn 提示出现「+N 腐蚀」（N 为 10）。若只有 6474、没有点数列表，`IsCorruptedItem` 可能仍为假，CorruptionTooltips 会当作未腐蚀件且对不上瓶子表，**提示空白**——这表示功能 8 没写全。
- 虹吸者三段：6495 与 6614，腐蚀点数 45。
- 闪避者一段：6483 与 6453，不要出现 6455。
- 涂完后装等选择器仍在。

## 9. 插件交叉（本功能）

- **CorruptionTooltips `purchaseable`**：52 瓶 → 效果加成列表，与上表物品编号一致。它 **不** 列出配套点数列表。注释里的段位有误（177995 / 178000 / 178014 / 178015），实现与验收以加成列表数字和细节-F8 第 3 节为准。
- **`loot`**：写死武器 172191→6567 等。Encounter Journal 若只带 1 条加成，插件会把缺失的写死列表补进**显示**；真装实例仍须服务端写上 6567–6572（功能 2），功能 8 不要往商店路径写这些列表。
- **idTip**：只报 BonusID 数字，不解释特效名。涂完立刻对照第 3 节。
- **Simulationcraft 插件**：`bonus_id=` 用 `/` 连接多条。AskMrRobot 把加成编进唯一键（`b6474b6455` 一类），换腐蚀会改变「是不是同一件掉落」，它不执行涂抹。
