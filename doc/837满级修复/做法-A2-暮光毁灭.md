# A2 暮光毁灭 — 官方光柱层做法

对照：8.3.7.35662（含热修，见 [设计-腐蚀-Blizzlike.md](设计-腐蚀-Blizzlike.md)）。家：`spell_corruption.cpp`。
第 1 层打桩仍是 `.labtwilight`（317147）。真装 318276 / ItemEffect **未做**。

本层把瞬间直线斩击改成官方那道从身上沿面向飞出的暮光光束，判定走 AreaTrigger 本体。

## 对齐的官方行为（2026-08-26 定）

- **含 2020-02 热修**：最多 10 目标、第 6–10 个半伤、打满 10 个光束消失。
- **扫到就打，会拉怪**：路径上任何可攻击目标（含未进战的怪）都结算，不做防拉怪过滤。这是官方 8.3 的著名行为，写进测试步骤，不当 bug。

## 官方光柱（不是追怪）

- 沿 **proc 时面向** 往前飞，约 **4 秒 / 25–30 码**，波浪视觉是 SpellVisual 93766。
- 扫到才结算，近的先、远的后。侧面 / 背后 / 脸没对准 = 0。
- 不跟着你、不锁定目标。穿墙（直线样条，不用 PathGenerator）。
- 伤 = 最大生命 6/12/18%。不打自己、不打友方。每目标独立暴击。

## 技能链

```
318276 / 318477 / 318478   Dummy 60/120/180 → $s1/10 = 6/12/18% 生命；LINKED_2 → 317147
317147                     隐藏 proc。RPPM 1 急速。4 秒 ICD。平砍+技能+敌对法术
317155                     CREATE_AREATRIGGER 19034，4 秒，宽 3 码
                           Target DEST_CASTER → DEST_DEST_FRONT
317159                     暗影 School Damage，BP=0，AT 用 SPELLVALUE_BASE_POINT0 传值
```

世界库：`spell_areatrigger` 19034 → 模板 **23070**（圆柱 r=3、h=10、ZOffset 0.3），TimeToTarget=4000。
早期 SQL 误写成球体 2307，脚本挂在用不到的模板上，`OnUnitEnter` 永远不跑。
2026-08-26 已把 `at_twilight_devastation` 绑回 23070。
样条四个点必须**互不相同**（0 / 9.24 / 18.48 / 28）：这个核心的 `InitCatmullRom`
会自动补虚拟控制点，输入点全是路径点，重复端点会做出零长度段导致停滞。

## 实现

- 317147 `PreventDefaultAction()`，对施法者 **DEST** 放 317155（不要 unit-self，否则 4 秒挂在玩家身上）。
- 317155 SpellScript 把 dest 钉在自己身上；`PreventHitDefaultEffect` 后由脚本手动
  `CreateAreaTrigger`（Haven 的 dest-HIT 路径不稳，手动建保证恰好一个 AT）。
- 位移走 `spell_areatrigger_splines`（数据驱动）；AI `OnCreate` 只留无 DB 行时的兜底样条。
- **伤害在 `at_twilight_devastation::OnUnitEnter`**：判定与视觉同源（AT 样条位置 + 球体 r=3 + 目标 hitbox）。
  没有平行的扫描事件。
  - 过滤：`_IsValidAttackTarget`（会打中立/未进战的怪 → 拉怪，官方行为）、不打自己、GUID 去重（每道光束每目标一次）。
  - 热修：`TWILIGHT_BEAM_MAX_TARGETS=10`、`TWILIGHT_BEAM_HALF_DAMAGE_FROM=6`；第 10 个之后 `at->Remove()`。
  - 伤害 = maxHP × (段 Dummy/10)%（6–10 号目标 ÷2），经 `CastCustomSpell(317159, SPELLVALUE_BASE_POINT0, …)` 传给结算。
- 317159 SpellScript 只在 BP 没传值时兜底填 maxHP%（直接 `.cast` 测试用）。**不 DealDamage**。
- 核心顺手修的真 bug：`AreaTrigger::RemoveFromWorld` 曾把 `_ai->OnRemove()` 调两次。
- GM 才发 `TWILIGHT_VISUAL` / `TWILIGHT_HIT`。不写 `spell_proc`。

## 验收

`.gm on` + HavenLab「暮光测试」（`.labtwilight`）+「一排桩」（`.labaoe`）：

- 面向那一排：5 个木桩先后挨打（约 2–4 秒内先近后远），不是同一帧；聊天窗 `TWILIGHT_HIT #1…#5` 序号递增。
- 右侧、背后、脸扭开：0。
- 人可以走；光束不跟着走、不追怪、不定身。
- 一段伤害约等于最大生命 × 6%，可暴击；`TWILIGHT_HIT` 报的 damage 与实际扣血同数量级（不再双倍）。
- 找 11+ 个目标（`.labaoe` 摆两排或野外怪堆）：第 6–10 个伤害减半，第 11 个不挨打且光束提前消失。
- 对未进战的野怪放：怪挨打并冲过来（拉怪 = 正确）。
- worldserver 不再打 `Invalid areatrigger miscid 19034`。
