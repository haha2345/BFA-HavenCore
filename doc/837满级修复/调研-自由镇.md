## 结论

自由镇在 Haven 里是「四王 C++ 已挂上、小怪走 SAI（SmartAI，数据表驱动的生物 AI）、instance 骨架极薄」的半成品（Haven）。本阶段一本要面对的缺口类是 **A 进本与进度、B 难度管道、C 克拉格、D 船长议会、E 战利品环、F 哈兰、G 小怪、H 物件与路、I 掉落、J 注册接线**。**K 明确不做**（钥石系统、词缀、觉醒尖塔、现役零售重做、`ChallengeModeMgr` 对 1754 的钥石装等）。

**Haven 现在能不能从门口打到尾王：** 不能按 8.3 规则打完四王并正确结算。能支持的是：玩家可以从泰拉加德海峡经区域触发器进 1754（分类：入口 `areatrigger` guid 56、`world_safe_locs` 6335）；四王与环赌过场 NPC 的 `ScriptName` 已接；没有顺序门禁（Haven：`CheckRequiredBosses` 基类恒 `return true`）；环赌过场链在 C++ 里从靠近戴夫走到托萨克入场开战是通的（Haven）。不能当成通关的：议会在留一名友好时控制器要求 `captainsDeathCount > 2` 才 `DONE` 并召唤箱子，打两名敌对永远到不了第三次死亡（Haven：`boss_council_o_captains.cpp:175`；R3 第 7 条：8.3 是打死两名敌对即结束）；议会箱子战利品列为 0（分类 / Haven）；克拉格战斗座骑 126841 的 `ScriptName` 为空，C++ 俯冲 / 邪恶轰炸不会跑在那只鸟上（Haven）；Haven **从不**施放 256056，只在 75% 调用 `ExitVehicle` 并在 `Reset` 里自己 `SummonCreature(126841)`（R3 第 5 条）；instance 掉线进入不拉到已通关位置（Haven：`OnPlayerEnter` 只尝试重放劳尔友好）。入口互传 NPC **9000000** 刷在 map 0（暴风城一带），不是用传送冒充击杀进度（Haven / 分类）。

**三难度管道（R3 第 1、2 条已钉）：** 35662 `Difficulty.db2` 难度 **23** 的 Flags = **133 / 0x85**，含英雄位 **0x01**（本地 db2；wago `https://wago.tools/db2/Difficulty?build=8.3.7.35662`）。因此 `Map::IsHeroic()` 在史诗五人上为真。Haven `instance_freehold.cpp:52-55` 两条独立 `if` 不是 `else if`，第二次乘法用已经改过的 `GetMaxHealth()`（`Creature.cpp:1799-1804`），史诗会先 ×2 再 ×1.33。英雄 2 只 ×2；普通 1 不硬乘。禁止把下面三套数字当成可以任选的「8.3 DBC」：暴雪 8.3 第 4 赛季说明的英雄血伤 +25%、非钥石史诗 +45% 是补丁文案（原文 *increased by*，`https://news.blizzard.com/en-us/article/23277657/visions-of-nzoth-season-4-content-update-notes`）；SQL `instance_difficulty_multiplier` 英雄 1.29 / 史诗 1.612 是 Trinity 自定义表（`bfa_world.sql:5087251-5087252`），血量通道只给五团本（`InstanceScript.cpp:136-148`），伤害通道只乘白字近战 `DIRECT_DAMAGE`（`Unit.cpp:742-747`），法术直伤传入 `SPELL_DIRECT_DAMAGE` 不走这张表；脚本 ×2 / ×1.33 是 Haven 硬乘，不是 DBC。Difficulty.db2 没有血伤乘区；35662 的 DBC 乘区在 `MapDifficulty` 地图 1754 的 ContentTuningID **500 / 501 / 502** 与 `ExpectedStatMod`（wago `https://wago.tools/db2/MapDifficulty?build=8.3.7.35662&filter[MapID]=1754`）。克拉格 `creature_template_scaling` 行是 DifficultyID=0、ContentTuningID=0（`bfa_world.sql:4316063`），Haven 现役血量主路径是模板 `HealthModifier` 加脚本硬乘，而不是那张 ExpectedStatMod 表。
