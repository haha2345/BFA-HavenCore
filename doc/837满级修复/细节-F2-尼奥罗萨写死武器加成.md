# 功能 2 细节：尼奥罗萨写死武器固定加成

对照 **8.3.7.35662**。设计正文：[2026-08-29-corruption-loot-ranks-design.md](../../docs/superpowers/specs/2026-08-29-corruption-loot-ranks-design.md)。  
战斗行为见 [设计-P6-尼奥罗萨武器.md](设计-P6-尼奥罗萨武器.md) 与清单 C 节；本文件只回答 **加成列表如何绑到物品实例上**。

## 1. 要解决的现象

六条独特效果和六条借用签名段的脚本已经能打。掉落和 `.labgear` 发出的毁灭之时只有装等加成 `1517`，实例上没有类型 23，穿上等于普通武器。

## 2. 十二把名单（不是「所有尼奥罗萨武器」）

Icy Veins「Corrupted Weapons」一节恰好这十二把带 **固定** 特效。同团本的 Warmace of Waking Nightmares（`172186`）等是 **随机** 腐蚀，走功能 4，禁止写进本表。

## 2.1 四种难度都会掉，特效不随难度变

十二把在寻找团队、普通、英雄、史诗 **都会掉**，同一物品编号。变的是物品等级，不是好效果、不是段位、也不是腐蚀点数。寻找团队的 An'zig Vra 仍是吞噬活力、腐蚀 35（6567），不会变成更低段、随机腐蚀或白板。

前十位首领装等：430 / 445 / 460 / 475。外壳与腐蚀者恩佐斯再高 10 级：440 / 455 / 470 / 485。

客户端依据：专用腐蚀树只有一个节点，物品上下文为 0，任意团本上下文都套同一条列表。按难度分叉的是另一棵装等树（430–475），不要改写死列表去「配合」难度。

公开页交叉：Warcraft Wiki 为多把武器提供四难度分页，腐蚀行与装备特效相同；Wowhead 各首领掉落指南切换难度时改装等、武器名单不变；Icy Veins 尼奥罗萨掉落表没有给任何一把标「仅史诗」（同页唯一种「仅史诗」是坐骑）。现役 Wowhead 已按后续资料片压装等，且 9.0.1 关闭了腐蚀，不能用今天的难度下拉框当 8.3 腐蚀证据。

Warmace（`172186`）等非写死武器同样四难度都掉，走功能 4 的随机池；随机段位也不随难度升高。

## 3. 加成列表里有什么

独特 6567–6572 与签名 6537 之后：SimC 显示 **腐蚀点数与效果在同一条列表**。挂上这一条即可同时得到 `ITEM_MOD_CORRUPTION` 和类型 23。不要再配 6455 这类纯点数列表。

这些效果 **没有** `腐蚀 -` 外壳前缀（清单已写）。客户端靠 ItemEffect 提示。

## 4. 本核要动的位置

| 位置 | 现状 | 功能 2 要它变成 |
|------|------|-----------------|
| `Loot::AddItem` | 有上下文则只 `GetDefaultItemBonusTree` | 写死武器实例含上表列表 |
| `GetDefaultItemBonusTree` | 匹配节点 ≠ 1 整棵跳过 | 专用树只有一个 Context=0 节点，**不要**为功能 2 改跳过条件。树 2819（随机武器）继续被跳过，交给功能 4 |
| `cs_misc.cpp` `.labgear` | `172187` 仅 `{ 1517 }`，注释写明无腐蚀加成 | 毁灭之时带转储确认的暮光加成；十二把走 `.labgear weapons` |
| `spell_corruption.cpp` | 六条独特 + 签名家族已有 | **不改** 战斗脚本 |
| 世界库掉落 SQL | 仓库 `sql/` 与 `DatabasesV1.1/` 未检索到这十二个物品编号 | 掉落行本身不是本功能的主修点；缺掉落是另一次数据任务。本功能保证 **一旦该物品被 `AddItem` 生成且上下文非空**，加成正确 |

## 5. 实现策略

**团本掉落（`ItemContext != NONE`）：** Wago 显示专用树 Context=0 单节点，`GetDefaultItemBonusTree` 应当已经写入固定列表。热修里的空树 3025 会被跳过，不影响专用树。展开函数仍做「没有则插入」，避免 ClientData 缺失时变成白板。

**`.labgear` / `.additem`：** 固定 `ItemContext::NONE`，**不套**默认树，必须在 `BonusListIDs` 里写上表列表。

抽出随机腐蚀之前：已是这十二个编号则 return，即使组 158 里也有 6567。

世界库当前没有这十二件的 `creature_loot_template` 行。补掉落与接线加成分开验收：先 `.labgear weapons`，再视需要补 SQL 掉落。

## 6. 净化

正式服净化会去掉效果和腐蚀。本阶段不做玛乌尔交互。实例设计必须允许将来删掉这些加成列表后武器变普通，因此 **不要** 把 ItemEffect 写进物品模板的静态 `Effects` 来「永久绑死」。

## 7. 验收

- `.labgear weapons` 后穿每把武器：对应驱动存在，人物面板腐蚀点数等于上表「以加成为准」列（转储改表则改期望）。
- 借用签名的六把：走已有 `spell_corruption_rank_driver`。毁灭之时按暮光 **三段**；Shard / Vorzz / Qwor / 眼柄 / Shgla'yos 按 **二段** 驱动（318482 / 318479 / 318485 / 318484 / 318487）。
- 同一角色再捡一件随机腐蚀胸甲，不得把写死武器的效果替换掉或叠上第二条随机特效。
