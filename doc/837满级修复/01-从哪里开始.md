# 从哪里开始

**第一刀：方案 A0（腐蚀数据是否真的在），然后 A1（无限之星）。不要先改团本或词缀。**

原因：

- 腐蚀是 8.3 独有、你最熟的系统；Haven 已经有 `Player::UpdateCorruption()`，缺的是数据和效果脚本。
- 五人本文件比团本厚，但验收需要 120 + 能看伤害的装。腐蚀管道通了，后面打本才有 8.3 的「味道」。
- 词缀是叠在五人上的一层。五人还不能通关时接词缀，分不清是王坏了还是词缀坏了。
- 尼奥罗萨 / 永恒王宫入口是独立坑，但比腐蚀大，且不挡你先把腐蚀打出来。

当前分支已经是 `endgame/corruption-stars`，fork 已配好。不用再开仓库，直接在这个分支改。
