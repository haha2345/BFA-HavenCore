# 进游戏验收：玛乌尔商店、泰坦净化、装等缩放、污染物

对照正式服 **8.3.7.35662**。

## 1. 进游戏前

1. 起 MySQL（端口 3307）→ `bnetserver` → `build/bin/RelWithDebInfo/worldserver.exe`。世界库相关 SQL 已经打进 live `bfa_world` / `bfa_hotfixes`，一般不必再跑一遍。
2. 改 `build/bin/RelWithDebInfo/worldserver.conf`（改完必须重启世界服）：

| 配置项 | 验收时建议 | 含义 |
|--------|------------|------|
| `Mother.ContaminantMode` | `1` | 货架一次列出全部 52 瓶。`0` 是正式服一周两次轮换（事件 201–208），只看当前窗 |
| `Mother.RequireCuriousCorruption` | 先 `0` 测净化窗；再改回 `1` 测任务门 | `1` 时未完成任务 58991（好奇的腐蚀）不能开净化 |
| `HavenLab.ChatNotify` | 测伤害时用 `1` | 只有 GM 账号能看见黄字；取值 `1` 要求**不要**开 `.gm on` |

3. 登录 8.3.7.35662，角色 120 级：

```
.gm on
.character level 120
```

点选自己，再发货币（尼奥罗萨的回响 **1803**、腐蚀纪念品 **1719**）：

```
.modify currency 1803 50000
.modify currency 1719 50
```

不要发货币 **1744**（那是 PTR 残留编号）。

4. 去心之密室找玛乌尔（生物编号 **152194**，出生 guid **210500001**）：

```
.go creature id 152194
.gps
```

出生点高度当初写成 **Z = 0**。若人掉到虚空或卡在地下，在锻造台地板上 `.gps` 记下真实高度，再改 `creature` 表该 guid 的 `position_z` 后重启（或临时 `.npc add 152194` 对照）。

## 2. 看加成列表时用什么、不要用什么

下表用途：分清「服务端真写上了哪些加成编号」和「插件自己猜出来的特效名」。

| 工具 | 能当证据 | 不能当证据 |
|------|----------|------------|
| **idTip** | 物品提示里的 `BonusID:` 数字 | 特效中文名 |
| **SimulationCraft 导出**（`/simc`） | `bonus_id=6552` 或 `bonus_id=6474/6455` | 伤害公式（公式在桌面模拟器，不在插件里） |
| **CorruptionTooltips** | 装备**已经腐蚀之后**，按链接里的列表认出「Infinite Stars I」 | 瓶子提示上的购买目录（它按物品编号查表，即使服务端没写 6552 也会写出特效名） |
| **Pawn** | 净化后「+N 腐蚀」那一行消失 | 伤害高低 |
| **SavedInstances** | 回响 1803、纪念品 1719 各减各的 | 装备加成 |
| **人物面板腐蚀条** | 穿脱、净化、打瓶之后腐蚀点数是否立刻变 | 单独证明写了哪一条 BonusID |

GM 发装语法：`.additem <物品编号> 1 <加成1>;<加成2>`。分号分隔，不要空格。`.labgear` 会发一整套板甲（含艾泽里特胸和传奇披风），**不能代替**「对白板件使用污染物」。

## 3. 功能 5：玛乌尔商店

商人必须是心之密室的 **152194**，不要找 155923。货是 **保存的污染物**（普通品质消耗品），不是成品腐蚀史诗。

### 3.1 货架

- [ ] 与玛乌尔对话能看到商人选项（脚本会强制挂出「浏览货物」，即使静态 `npc_vendor` 是空的）。
- [ ] `Mother.ContaminantMode = 1`：货架上能看到远多于一轮的瓶子，目标是 **52** 瓶。
- [ ] `Mother.ContaminantMode = 0`：`.event activelist` 里应能看到 201–208 中当前窗；货架件数大约 6 或 7，不是 52。可用 `.event start 201` 等对照 [细节-F5](细节-F5-玛乌尔商店.md) 第 5 节八轮名单。
- [ ] AllTheThings 里玛乌尔原来就有的三阶精华、惊魂幻象容器 **173363**、邪恶核心 **175062** 仍在，没有被污染物行盖掉。

### 3.2 买一瓶无尽之星一段

- [ ] 买物品 **177983**，扣回响（扩展费用 **6801**，**5000** 枚货币 1803）。
- [ ] 背包里是普通品质消耗品，不能装备。
- [ ] **idTip 看这瓶本身：没有 BonusID 6552。** 商人行的 BonusListIDs 必须是空的。CorruptionTooltips 仍可能在瓶子上写出 Infinite Stars I，那是插件目录，不要当成服务端写了加成。
- [ ] 买完但还没对装备使用：人物腐蚀条不上升。SavedInstances：1803 减少，1719 不变。

### 3.3 抽查价签（Mode=1 时）

下表用途：确认同金额的两档没有接反。

| 物品编号 | 应看到的特效 | 回响 | 扩展费用 |
|----------|--------------|------|----------|
| 177995 | 虹吸者一段 | 4250 | 6799 |
| 177972 | 闪避者三段 | 4250 | 6800 |
| 177985 | 无尽之星三段 | 15000 | 6810 |
| 178006 | 暮光毁灭三段 | 15000 | 6793 |

虚空回响三瓶编号是 **三段 / 二段 / 一段** = 177967 / 177968 / 177969，不要按编号从小到大当成一段起。

## 4. 功能 6：泰坦净化

打开方式是玛乌尔对话选项 **「I want to purify a corrupted item.」**（目前是英文占位），**不是**右键装备，也**不要**对装备施放法术 317647。标题应是暴雪物品交互窗 **Titanic Purification**（泰坦净化），按钮 Purify。

发一件带无尽之星二段和装等选择器的非艾泽里特件（尼奥罗萨板甲护腕，`.labgear` 里没有艾泽里特选择器 4775）：

```
.additem 174170 1 1517;6553
```

### 4.1 成功净化

- [ ] 货币 1719 至少 5 枚。放入该护腕，点 Purify。
- [ ] idTip：6553 消失，**1517 还在**（物品等级没有掉回模板）。
- [ ] SavedInstances：1719 减 5，1803 不变。
- [ ] 穿着时净化：人物腐蚀下降；无尽之星光环应消失（必须经过穿脱那一套属性重算，不能只改加成数字）。
- [ ] 客户端认为这件装备不再是腐蚀物品；Pawn 的「+N 腐蚀」消失。
- [ ] **同一窗口可以连续再净第二件**，成功后不要被关掉。关窗应走普通关闭交互，而不是每次成功都强制关。

### 4.2 应失败的情况

- [ ] 1719 不足 5：提示货币不够（游戏错误 `ERR_ITEM_INTERACTION_NOT_ENOUGH_CURRENCY`），装备加成不变。
- [ ] 放入未腐蚀装备（例如 `.additem 174170 1 1517`）：失败，1517 仍在。
- [ ] `Mother.RequireCuriousCorruption = 1` 且任务 58991 未完成：对话里**没有**净化选项（商人选项仍在）。完成任务的对话是 **「I need to speak with you about this corruption.」**，会给击杀计数 163274 与 163275。

## 5. 功能 8：对装备使用污染物

像附魔一样：对准背包或已装备槽里的**那一件实例**，不要打开泰坦净化窗来涂。瓶子用一次少一瓶。

白板件（不要用艾泽里特头/肩/胸，不要用饰品）：

```
.additem 174170 1 1517
.additem 177983
.additem 177985
.additem 177973
.additem 177997
.additem 177970
```

### 5.1 正向：写上与掉落相同的列表

- [ ] 白板护腕使用 **177983**：idTip 出现 **6552**，穿上有无尽之星一段。`/simc` 出现 `bonus_id=6552`（以及原来的 1517）。人物腐蚀上升。CorruptionTooltips 应按链接里的 6552 认出 Infinite Stars I。
- [ ] **装等选择器 1517 仍在。**
- [ ] 背包里的瓶子和已装备槽里的白板件都能对准。
- [ ] 权宜之计一段 **177973**：同时出现 **6474** 与 **6455**。Pawn 出现「+N 腐蚀」（N 为 10）。若只有 6474、没有点数列表，面板可能仍当未腐蚀，CorruptionTooltips 会空白——那是没写全。
- [ ] 虹吸者三段 **177997**：**6495** 与 **6614**，腐蚀点数 45。不要误成 6470。
- [ ] 闪避者一段 **177970**：**6483** 与 **6453**。不要出现 6455。

### 5.2 不能原地升段

- [ ] 已带 6552 的同一件再使用 **177985**：施法失败，6552 不被 6554 覆盖，瓶子不该被吃掉。
- [ ] 先在玛乌尔处净化，再使用 177985：成功，变为 **6554**。

### 5.3 负向：必须失败（装备不变、瓶子还在）

- [ ] 饰品：`.additem 169311 1 1517` 再打任意污染物。
- [ ] 艾泽里特赋能护甲：`.labgear` 胸甲 **174164**（带 4775）再打。
- [ ] 艾泽拉斯之心 **158075**。
- [ ] 传说披风阿什吉拉卡马斯 **169223**。普通披风不要被误拒。
- [ ] 已带独特武器列表的 An'zig Vra：`.labgear weapons` 后穿 **172191**（列表 **6567**），再打商店通用瓶。
- [ ] 可选：工程护目镜一线（常见编号 165733 / 165734 / 165735 / 165738）和炼金石饰品（152559 / 165928）。拒绝逻辑走「艾泽里特或饰品」检查；若某件护目镜不是艾泽里特赋能件，以进游戏现象为准，不要为了拒它去猜物品分类。

## 6. 功能 7：装等缩放收口

测的是**穿在身上的那件腐蚀装备的物品等级**，不是攻击强度、也不是 Pawn 分数。不要用 `.labstars` / `.labtentacle` 代替（那是光环打桩，不走这件装的物品等级）。

伤害证据：Details! 战斗记录，或 `HavenLab.ChatNotify = 1` 时的系统黄字。法术编号：无尽之星落星 **317265**，龟裂创伤跳伤 **318187**，附肢抽打 **316835**。

### 6.1 无尽之星应随装等变

两件同一模板、同一腐蚀段、物品等级明显不同。低档用默认模板等级（只写 6553），高档加上 `.labgear` 常用的选择器 **1517**：

```
.additem 174170 1 6553
.additem 174170 1 1517;6553
```

先看两件提示上的物品等级是否真的不同（约 430 对约 475 是细则里的量级；只要差一截即可）。分别只穿一件，对木桩打一会儿：

- [ ] 高装等那件的 317265 明显高于低装等。
- [ ] 两件不要叠在一个人身上再比（多件同特效会按段求和，会把对照打乱）。

### 6.2 对照：不该随装等改档的

- [ ] 暴戾三段：`.additem 174178 1 1517;6482;6470`（或先打 177994）。把 1517 换成更低装等再穿：人物面板暴击百分比仍是同一档（6% / 9% / 12% 不跳档）。
- [ ] 虚空之鞭回归：`.labgear weapons` 穿 **172197**，伤害仍随该武器物品等级走，不要回到攻强百分比。本任务没有改这条路径，只确认没被带坏。
- [ ] 不要去验收暮光毁灭、虚空回响是否随装等（它们仍是最大生命值百分比）。

### 6.3 另外两条已改的伤害（有时间再测）

- [ ] 扭曲的附肢：两件不同装等的 6543 一线，316835 跳伤应有差。
- [ ] 龟裂创伤：两件不同装等的 6573，318187 跳伤应有差。团本英雄训练假人可能免疫这条，换活怪。

## 7. 已知、不要当成失败的

| 现象 | 说明 |
|------|------|
| 买了瓶子还不能用 | 只做完商店、没做到污染物时才会这样。四项都接上之后，买了就应该能打白板件 |
| 瓶子提示上有 Infinite Stars I | CorruptionTooltips 的购买目录，不是服务端 BonusID |
| 净化对话是英文 | 占位文本，不挡机制关账 |
| 玛乌尔浮在空中或掉进地图 | 出生点 Z=0，用 `.gps` 校正高度 |
| `.labstars` 伤害和真装不一致 | 打桩光环不带这件装的物品等级，功能 7 不看它 |
| 客户端技能提示仍写攻强/法强公式 | 热修前的提示字符串，35662 战斗数字以战报为准 |
