判定（由 Task 3 执行，本任务不改伤害）：

1. 系数为 0：`CalcValue` 走基础点数，传入的物品等级被忽略。本四条均非 0。
2. 系数非 0 且 `Class == 0`：**禁止** 盲调 `CalcValue`（会打出 0）。本四条 **均不是** 这种情况。
3. `Class` 为 −8 / −9 且 `attr354=1`：才是热修后的物品等级缩放路径。本四条均为 **−9 + attr354**，与已接线的虚空之鞭同一条门闩。Task 3 应对无尽之星 / 附肢 / 龟裂创伤的段位光环效果 0 走 `CalcValue`。
