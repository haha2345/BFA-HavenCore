# 调研：冈克机器人身份、重复召唤、激活与重置

原子只处理地图 2097 上三对静态喷射机器人 / 剧毒畸体：它们是谁、会不会被再召唤、开战前什么把机器人放开、wipe / 重置 / DONE 时这三只怎么记。技能冷却、伤害、半径、喷雾净化、粘液 AI 不在这里定案。客户端目标 8.3.7.35662。刷新行 VerifiedBuild=31478 不是 SpellEffect，也不是 CreatureDifficulty。

R3 核对见 `_tmp_grok/dungeon-loop-20260930/gunker-r3.md`。视频只引用 Codex 的 `video/codex-review/observations.md`。作者没有看画面。下面若与 R1 原文冲突，以 R3 为准。本篇不是实施方案，也不表示冈克整场已修好。

## 结论

1. 喷射机器人只有三行静态 creature，与三只剧毒畸体一对一，出生 XYZ/O 全等。不要再召唤第 4 只。模板 ScriptName 保持空；机器人脚本绑在这三行自己的 `creature.ScriptName`。
2. R1「毒元素 30 行，不要凑成 3」是错的。30 = 史莱姆元素 150165 共 14 + 剧毒潜藏者 150169 共 13 + 畸体 3。只有畸体是本原子的解除身份。150165 / 150169 的 addon 是 237007，坐标不与三对重合。
3. 戈巴马克 DONE 不是前置。Codex 看过的 `1330.png`：右侧「1/1 击败冈克 9:46」，同时「0/1 击败戈巴马克」。`MoveInLineOfSight` 里这道门要删除。删掉它不等于零击杀就能开战，也不换成「mask 齐了再摘 300859」。三只剧毒畸体死后释放对应机器人，再由玩家拉冈克。顺序由 2019-05-08 Squishei 亲测 PTR 预览、2020-02-02 Icy Veins 旧指南（不抄伤害和路径）和 Codex 已看的 BFA 片段一起钉住：180 秒第一只 tooltip 为 150168，185/190 已是尸体，22:18:25 机器人「系统已恢复」；240–275 秒第二只从约 63% 打到尸体并离战，22:19:50「传感器重置完成，侦测到高浓度剧毒样本」，这只 entry 没读出，不猜；350–440 秒第三段之后三台机器人先到，冈克 100% 仍待战。同坐标三对和畸体身上的 300838 与这条一致。PTR 单独不能证明 8.3.7。不用 R3 旧文里「前两段没看」反推顺序不存在。300859 消退时刻仍未证，和这道条件分开。全片不是每一帧都看过。
4. 三只畸体模板 faction 35、level 1–1。35662 的 FactionTemplate 在 core 按 uint8 截断后，35 对玩家友好，玩家不能攻击。这不是「DB2 坏了」：FriendGroup 原始值 513，`513&255=1`。官方等级和生命没有可读的 CreatureDifficulty parent。一击死不是战斗修完。
5. 300838（Trapped Squirt Bot）在三只畸体上，300859（Viscous Goop）在冈克 0898 上，三只机器人 addon 为空。两条都是假人光环加一条客户端 SPAWN，服务器不因此召唤，也不因此免疫。
6. 释放和开战是两段。对应畸体死后机器人先就位，喷雾和遭遇框在玩家拉进战斗之后才出现。第三只死亡不自动拉冈克。世界路径、两个临时站、官方伤害和血量、wipe 画面仍未证。现行临时站只是 Haven 局部坐标。脚本里已有的三只静态 `Respawn(false)` 不是已证官方重置，也不能因为没看见 wipe 就删掉。603 秒连续帧证明的是死亡时 3 个遭遇框被清掉，不是实体消失或回家。

## 阵营与难度

正确头是 `<4s9IHh7I`。FactionTemplate 实测 locale=`0xFFFFFFFF`，flags=4，IndexField=0，layout `0xDB7D5E30`，文件大小与 core 公式一致。旧 reader 的 flags=-1、id_index=4 作废。

FriendGroup 原始解包：16 是 512，35 是 513。core 字段是 uint8，反应函数看到的是 `512&255=0`、`513&255=1`。不要把 513 写成非法行。Faction 14 与 31 的 ReputationIndex 都是 -1，不走声望。

截断后：35 的 FriendGroup 含玩家位，与玩家模板 1（玩家|联盟）和 2（玩家|部落）互相友好，不能攻击。16 的 EnemyGroup 含玩家位，与这两个玩家模板互相敌对，`IsHostileToPlayers()` 为真。35 与 16 互相中立。16 是「已证实的敌对模板」，不是这三只畸体在 DB2 里的模板。

CreatureDifficulty layout `0xA7D21F05`，可读 parent 14303 条，没有这三只畸体、三只机器人或冈克。Id 154744 与 154746 的 parent 是 143448 与 143450，那是别的生物的难度行。另有 1 条加密记录（section nrec=1）按文件系统 Skip 未读。没有官方生命或等级可填。`creature_template_scaling` 仍以 R2 的 0 行为准，本轮不猜缩放。

## 现行源码（Haven，不是零售路径）

认领条件在 `SquirtIsOwnedStatic`：地图 2097，且只能是 0910=154741、0912=154746、0911=154759。

`MoveInLineOfSight`：玩家进视野且 `DATA_KING_GOBBAMAK==DONE` 时去掉 300859，并尝试去掉免疫旗。刷新旗是 0，300859 也不是免疫光环。这道门与 1330 帧矛盾。删掉它之后，开战仍要等三只畸体释放完，见结论 3。300859 摘不摘不由这道条件决定。

开战 `EnterCombat` 后 `RecoverDeadSquirts`，再让机器人 Begin。`SquirtUsesTemporaryStation` 把 154741、154759 传到源码里的两个临时点，154746 留在出生点。注释已写明不是零售路径。

wipe：`EnterEvadeMode` 把状态写成 FAIL，End，再 `RecoverDeadSquirts` → `Respawn(false)`。没有 `SummonCreature`。DONE：`JustDied` 里 `_JustDied` 后 Notify；`GunkerDoneIsTerminal` 让之后的 Reset / 进战 / 脱战 / 再死亡直接返回，不再 Respawn。录像没有 wipe，所以「失败后是否复活」不能写成已看过。

临时站保留为未决局部行为，见后续项。不要把它们升级成官方移动。
