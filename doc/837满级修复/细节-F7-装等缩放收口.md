# 功能 7 细节：装等缩放收口

对照 **8.3.7.35662**。设计正文：[2026-08-30-mother-purify-ilvl-design.md](../../docs/superpowers/specs/2026-08-30-mother-purify-ilvl-design.md)。  
战斗脚本结构已经验收过。本功能只改 **三条仍按攻击强度 / 法术强度结算的伤害**，并改掉文件头里把光环 285 写成 `average(item)` 的那几句。

## 1. 光环 285 是什么

枚举：`SPELL_AURA_LINKED_2 = 285`。处理函数：`AuraEffect::HandleAuraLinked`。套上时施放触发法术（无尽之星是 317257），卸下时去掉。它 **不算伤害**。

SimulationCraft 的 `effectN(1).average(item)` 读的是同一条段位法术 **效果 0** 上的物品等级系数（无尽之星大约 32.20）。那是模拟器自己的叫法，不要写进 C++ 注释当光环类型。

`spell_corruption.cpp` 文件头对暮光毁灭已经写了 `LINKED_2`。无尽之星那段仍写 Dummy 83/208/312 和「aura 285 的 average(item) 未接线」。第二轮质询：不是整份文件头在撒谎，而是无尽之星那一段把模拟器编号和客户端光环混在一起。功能 7 改伤害函数时必须改文件头，使两者一致。

## 2. 2020-01-23 热修（Bornakk）

伤害改为按 **那一件腐蚀装备的物品等级** 计算、不再跟攻击强度 / 法术强度一起晃的：

- 无尽之星
- 扭曲的附肢
- 龟裂创伤
- 虚空之鞭

仍不随物品等级变的：

- 暮光毁灭、虚空回响：最大生命值百分比（后来只动过目标上限和玩家对战减免）
- 暴戾 6% / 9% / 12% 等百分比被动
- 权宜之计、击穿等百分比或固定等级被动

Ask Mr. Robot 用 430 与 485 对比：同一条暴戾仍是 6 / 9 / 12。团本难度改的是物品等级，不是腐蚀段位；同一段无尽之星在更高装等上可以打得更痛，那是本功能，不是功能 3。

## 3. 本核现状

下表用途：对照热修应当怎么算，以及 `spell_corruption.cpp` 现在怎么算。

| 特效 | 热修后 | 当前代码 | 本功能 |
|------|--------|----------|--------|
| 虚空之鞭 317290 | 效果 0 系数约 40.058，职业列 −9 | `LashOfTheVoidDamage` 已 `CalcValue` + 物品等级 | **保持，不改** |
| 无尽之星 318274 / 318487 / 318488 | 效果 0 系数约 32.20，职业列 −8 | `InfiniteStarsBaseDamage` 读效果 1 Dummy 百分比，再乘 `max(攻强, 法强)`。`useCalc` 打在系数 0 的 Dummy 上 | **要改** |
| 扭曲的附肢 318481 / 318482 / 318483 | 效果 0 系数约 4.81 | `TwistedAppendageTickDamage` Dummy 百分比 × `max(攻强, 法强)` | **要改** |
| 龟裂创伤 318272 | 效果 0 系数约 2.37，职业列 −9 | `GushingWoundTickDamage` 用 318187 效果 1 基础点数百分比 × `max(攻强, 法强)` | **要改** |
| 暮光毁灭 / 虚空回响 | 最大生命值百分比 | 已按最大生命值百分比填 | 不在本功能 |
| 暴戾等百分比 | 固定百分比 | 固定百分比 | 不在本功能 |
| 急速脉搏等触发等级 | Bornakk 未写 | 已有 Dummy / Scaled + 部分 `CalcValue` | 不塞进本功能 |

`CorruptionRankItemContext` 已经能从段位光环的施法物品 GUID 取出 `itemId` 和 `GetItemLevel(player)`。虚空之鞭证明这条路径可用。无尽之星不要再读 `EFFECT_1`。

本核 `CalcValue` 的门闩（实现时必须先转储再接线）：

1. 效果系数为 0：直接返回基础点数，传入的物品等级被忽略。权宜之计 6%、暮光 60 都走这条， **不要** 再乘装等。
2. 系数非 0 且缩放类别（`Scaling.Class`）为 **0**：函数会 **立刻返回 0**。34769 的 Spell dump 里龟裂创伤、扭曲的附肢、无尽之星三段标题有的没有 `Scaling Spell (-8)`。任务 0 必须打 35662 的 `SpellScaling`：若类别仍为 0，不能盲调 `CalcValue`，应对照虚空之鞭已接线的那条（属性 354 + 非 0 类别）再决定；SimulationCraft 在「无缩放类别 + 属性 354」时用 `RandPropPoints.DamageSecondary`。
3. 类别 **−8 / −9** 且带属性 354（随物品等级缩放）：这才是热修后的星 / 鞭 / 创伤 / 附肢路径。
4. 类别 **−7**、无属性 354（急速脉搏等次级等级）：应按玩家等级， **不要** 为了「统一传 itemId」而把战斗等级装等倍率乘进去。本功能 **不改** 这些触发。

客户端技能提示里仍可能留着 `$s2/100*$max($AP,$SP)`，那是热修前公式，不能当 35662 战斗数字。击穿是 **2% / 3% / 4%** 暴击伤害，不是 6/9/12（那是权宜之计那一组）。

污染物使用法术 324889 的主效果是 223（改加成）， **不是** 战斗段位光环。战斗段位是 318274 一线。文件头若继续把 324889/90/91 写成「物品包装光环」，应改成：324889 一线是污染物使用法术；穿装触发走 318274 一线。

## 4. 改法（与虚空之鞭对齐）

对无尽之星、附肢、龟裂创伤：

1. 用已有 `CorruptionRankItemContext` 取物品编号与物品等级。
2. 对 **段位法术效果 0** 调用 `effect->CalcValue(owner, nullptr, owner, nullptr, itemId, itemLevel)`。
3. 多件同特效仍按现有「各段求和、不是只取最高」的规则，除非某条特效正式服不叠加（无尽之星已按求和验收过，不要顺便改叠加规则）。
4. 禁止手写装等到伤害的常数表。
5. 龟裂创伤不要再拿 318187 的 Dummy 百分比当伤害；318187 仍是跳伤害法术，填入的点数应来自 318272 效果 0 的 `CalcValue`。

多件装备、不同装等同时穿无尽之星时：每一段光环应对应自己的那件装备做 `CalcValue`，再按现有求和规则相加。不要用人物身上「任意一件」的装等去算所有星星。

## 5. 不要做的

- 不要改 `HandleAuraLinked`。
- 不要把暮光毁灭、虚空回响改成物品等级。
- 不要让暴戾 / 权宜之计百分比随装等变。
- 不要改急速脉搏等 −7 次级触发的 `itemId` 传参（本功能不碰它们）。
- 不要改 `Rate.CorruptionDrop` 或掉落抽签。

## 6. 验收

进游戏操作勾选见 [验收-玛乌尔净化装等污染物.md](验收-玛乌尔净化装等污染物.md) 第 6 节。仓库无单元测试。进游戏：

- 两件胸甲同一 `bonus_id=6553`（无尽之星二段），物品等级分别约 430 与 475。对木桩看 317265：高装等应更高。用 Details! 或 HavenLab 看战斗记录。
- 同一人换成暴戾三段（6482 + 点数列表），人物面板暴击百分比不随把 430 换成 475 而变成另一档 6/9/12。
- 虚空之鞭回归：写死武器 172197 伤害仍随装等，且不要回到攻强百分比。
- 文件头不再声称光环 285 是 `average(item)` 未接线。

## 7. 插件交叉（本功能）

伤害公式在 **桌面** SimulationCraft `Data/simc-bfa-dev/engine/player/unique_gear_bfa.cpp`，不在 `/simc` 插件里。8.3 插件只负责导出 `bonus_id`。

| 特效 | 桌面 SimC | 与本核对应 |
|------|-----------|------------|
| 无尽之星 | 驱动法术 `effectN(1).average(item)`，伤害法术 317265 | `EFFECT_0` 的 `CalcValue` + 该件物品等级 |
| 龟裂创伤 | 驱动 318272 的 `effectN(1).average(item)`，跳伤害仍是 318187 | 不要再用 318187 效果 1 Dummy × 攻强 |
| 扭曲的附肢 | 驱动法术 `effectN(1).average(item)`，再交给触手 316835 | 同样走效果 0 |

SimC 的 `effectN(1)` 是从 1 起算，等于本核 `EFFECT_0`。Pawn 只给装备打分，**不能**用来验收这条伤害。WeakAuras 2.18.4 没有 8.3 腐蚀模板，不要从 WA 猜 318274。
