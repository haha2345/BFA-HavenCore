# 功能 5 细节：玛乌尔商店（用回响买污染物）

对照 **8.3.7.35662**。设计正文：[2026-08-30-mother-purify-ilvl-design.md](../../docs/superpowers/specs/2026-08-30-mother-purify-ilvl-design.md)。  
本文件只回答：**货架上是什么、多少钱、怎么轮换、世界库要补什么**。写入装备是功能 8。

## 1. 清单原句为什么不能按字面做

「用回响买现成腐蚀装」会让人以为商人表里是带 `BonusListIDs` 的史诗。正式服 2020-05-19 起，玛乌尔卖的是 **保存的污染物**（Preserved Contaminant）：普通品质消耗品，使用时才把加成写到玩家指定的装备上。暴雪新闻 [23453347](https://worldofwarcraft.blizzard.com/en-us/news/23453347) 原文是 “synthetic Corruption powers”，并且写明第四赛季装备和曾经泰坦净化过的装备可以再打上。

心之密室里同一 NPC 还卖三阶精华、惊魂幻象容器（173363，1750 回响）、后来还有邪恶核心（175062，2000 回响）。那些 **不是** 本功能的腐蚀货架。实现时不要覆盖已有精华行；本功能只追加 52 瓶污染物。

## 2. 商人

| 项目 | 值 |

| 商人生物编号 | **152194** |
| 同平台任务/事件模板 | **155923**（没有售卖清单，不要给她挂 `npc_vendor`） |

Wago 该版本 `Creature.db2` 里精确名为 MOTHER 的模型条目可能对不上 152194。商人编号仍以 Wowhead / AllTheThings 坐标为准，实现时用世界库 `creature` 在地图 2215 上的 guid。

本地 AllTheThings 2.0.8 的 `n(152194)` 有精华和容器，没有 177955+。SavedInstances 8.3.4 跟踪货币 1803。交叉验证时以 Wago `ItemSparse` / `ItemExtendedCost` 和暴雪新闻为准，不要用 AllTheThings 当污染物目录。

本仓库 `sql/` 里没有 152194 的污染物 `npc_vendor` 行。`VendorItem` 结构已有 `ExtendedCost`，污染物行的 `BonusListIDs` 保持空。

## 3. 52 瓶污染物（物品本身）

`ItemSparse` 特征：品质普通、装备栏位为空、拾取绑定、需求等级 120。编号 **177955** 以及 **177965–178015**。 **177956–177963 空号**。 **177964** 是武器附魔「力量倍增」，`ItemEffect` 误指向 324680，当作脏数据，不要当第六瓶致命之势。

显示名不含 Rank。段位写在使用法术名里（例如「腐蚀 - 无尽之星 1」）。虚空回响三件的编号顺序是 **三段、二段、一段**（177967 / 177968 / 177969），不要按编号递增当成一段起。

完整「物品 → 法术 → 树 → 列表」在 [细节-F8-污染物添加腐蚀.md](细节-F8-污染物添加腐蚀.md)。商店侧只需要：这 52 个 `item` 出现在 `npc_vendor` 里，并带对的 `ExtendedCost`。

## 6. 回响来源（本功能不新做）

尼奥罗萨部分首领脚本已经 `DoModifyPlayerCurrencies(1803, …)`，数量大约 11–30，接近 2020-05-19 **涨价之前** 的量级；涨价后零售单次首领大约 75–125，且每周每种首领第一次。主脑与腐蚀者恩佐斯在本核 **没有** 发放。突袭、幻象、世界任务、PvP、大秘境产量也不在本阶段。

功能 5 的验收用 GM 给货币即可。不要在本阶段把十个首领的发放改成零售表，也不要把 1803 做成账号共享。

## 7. 本核缺口

- 没有玛乌尔污染物商人行。
- 没有轮换事件。
- 商人 NPC 标志 / 对话需与功能 6 共用 152194，不要做成两个生物。

## 8. 验收

进游戏操作勾选见 [验收-玛乌尔净化装等污染物.md](验收-玛乌尔净化装等污染物.md) 第 3 节。摘要：

- 与 152194 交易，能看到污染物（轮换模式至少当前轮；`all` 模式 52 瓶）。
- 买一瓶无尽之星一段：扣对应回响，背包物品 177983，品质普通，不能装备。
- 商人行没有给 177983 填加成列表；用 **idTip** 查看该消耗品本身不应带着 6552。CorruptionTooltips 仍可能在瓶子提示上写出「Infinite Stars I」，因为它按物品编号查 `purchaseable`，**不能**当成服务端写了加成。
- 买完再穿装备，人物腐蚀不应因为「买了瓶子」而上升，只有功能 8 使用之后才上升。SavedInstances 应只看到 1803 减少，1719 不变。
- AllTheThings 里 152194 已有的精华 / 173363 / 175062 行必须还在，不要被污染物迁移盖掉。

## 9. 插件交叉（本功能）

- **AllTheThings 2.0.8** `n(152194)`：描述是用回响卖 **三阶精华**（须账号上已解锁），坐标 `48.15, 72.54`，界面地图 1473。商品：173363 = 1750 回响；175062 = 2000；各三阶精华 = 2500。**没有** 177955+。同文件 `n(155496)` 拉希奥卖 174876（1719 × 25000）和用 **1755** 买的另一份 173363，不要和玛乌尔货架混在一起。
- **CorruptionTooltips** `purchaseable`：52 瓶物品编号与细节-F8 一致，可当「商店卖的是消耗品、不是成品史诗」的第二份目录。注释里的 I/II/III 有几处写错，以加成列表数字为准。
- **SavedInstances** 把 1803 和 1719 分成两种货币跟踪。
- TSM / Auctionator 里没有这批消耗品，不要去扫专业或拍卖行表。
