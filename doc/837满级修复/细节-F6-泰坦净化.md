# 功能 6 细节：泰坦净化（从装备上卸掉腐蚀）

对照 **8.3.7.35662**。设计正文：[2026-08-30-mother-purify-ilvl-design.md](../../docs/superpowers/specs/2026-08-30-mother-purify-ilvl-design.md)。

## 1. 它不是背包物品

Wowhead 法术 [317647](https://www.wowhead.com/spell=317647/titanic-purification) 的唯一效果是完成任务，杂项值为 0。任务 [58991](https://www.wowhead.com/quest=58991/curious-corruption)（好奇的腐蚀）完成后，文案是 “Titanic Purification system available”。维基写明：任务里点「激活」 **不会** 真的净化那件装备。

真正净化是玛乌尔对话打开的 **物品交互界面**（和艾泽里特重铸那种「放进框再点按钮」同类）。本地 BlizzMove 从 8.3.0 起登记的就是 `Blizzard_ItemInteractionUI` / `ItemInteractionFrame`。Blizzard Watch 与 Icy Veins：花费 **5** 枚腐蚀纪念品（货币 **1719**），同时去掉好效果和腐蚀点数。PTR 文章曾写货币 **1744**，35662 的表和 SavedInstances 都是 **1719**，不要用 1744。

## 2. 客户端表 `UiItemInteraction.db2`

下表用途：分清 PTR 残留行和正式服净化行。

| 行 ID | 标题 | 按钮 | 花费 | 货币 | 交互法术 | 用途 |
|-------|------|------|------|------|----------|------|
| 1 | Cleanse Reforger | Cleanse | 32 | 无 | 13262 | PTR 残留，不要发给 8.3.7 客户端 |
| 2 | Cleanse Reforger | Cleanse | 32 | 无 | 0 | PTR 残留 |
| 3 | Titanic Purification | Purify | **5** | **1719** | 0 | 正式服泰坦净化 |

第 3 行的帧类型为 0，对应 8.3 枚举 `ItemInteractionFrameType.CleanseCorruption = 0`。不要用 9.x 的 `Enum.UIItemInteractionType.CleanseCorruption = 2` 去套 8.3.7。

说明文字：把腐蚀物品放进来，点 Purify，去掉装备上的好效果和腐蚀。

本核有 `UiItemInteractionMeta`，没有 `LOAD_DB2`，没有 `sUiItemInteractionStore`。实现时加载，花费与货币 **只读这一行**，禁止再写死 5 和 1719 到逻辑里（常量可以指向表，表才是权威）。

## 3. 操作码（已声明，未处理）

| 方向 | 宏 | 编号 | 当前 |
|------|----|------|------|
| 客户端 → 服务器 | `CMSG_PERFORM_ITEM_INTERACTION` | 0x3231 | `STATUS_UNHANDLED`，`Handle_NULL` |
| 服务器 → 客户端 | `SMSG_UI_ITEM_INTERACTION_NPC` | 0x283C | 空处理 |
| 服务器 → 客户端 | `SMSG_ITEM_INTERACTION_COMPLETE` | 0x28CE | 空处理 |

没有 8.3.7 公开嗅探。按同类 8.3 物品包与客户端 Lua（`C_ItemInteraction`）经验冻结：

- 打开：NPC 的对象 GUID + 交互表 ID **3**。标题、花费、货币由客户端自己查 DB2。
- 执行：至少带待净化物品的对象 GUID；NPC GUID 中等把握（与修理包同形）。Lua 的 `PerformItemInteraction()` 无参，待处理物品先在客户端 `SetPendingItem`。
- 完成：空包或回物品 GUID，中偏低把握。净化行的 `InteractionSpellID` 为 0，没有施法可等，所以更需要完成包清槽。

关闭窗口更可能走已有的 `CMSG_CLOSE_INTERACTION`，不要新造关闭 opcode。

错误码已有：`ERR_ITEM_INTERACTION_NOT_ENOUGH_GOLD`、`ERR_ITEM_INTERACTION_NOT_ENOUGH_CURRENCY`。

本核 `UNIT_NPC_FLAG` / `GOSSIP_OPTION_*` **没有**「物品交互」这一项。打开方式是 **gossip 选项**，不是右键即开。玛乌尔同时是商人、任务和净化，不能做成单一 NPC 标志。

## 4. 解锁任务

| 任务 | 作用 |
|------|------|
| 58991 好奇的腐蚀 | 第一次获得腐蚀装后自动接。找拉希奥问腐蚀物品，再找玛乌尔。完成法术 317647。 |
| 59000 腐蚀的要素 | 另一条也会打开同一套系统 |

任务进行中的「激活泰坦净化系统」只完成任务。 **之后** 再点净化台词，服务器才发 `SMSG_UI_ITEM_INTERACTION_NPC`。

世界库若缺这些任务 / 对话，用 `sql/updates/world/` 补。验收配置可跳过任务，默认应对齐正式服。

## 5. 改装备：禁止 `ClearBonuses()`

`Item::ClearBonuses()` 会清空全部加成列表并按模板重建。物品等级选择器（例如 1517）、品质列表会一起没掉。净化只能剥腐蚀相关列表。

判定一条加成列表要不要剥（与 `ItemAlreadyHasCorruptionEffect` 同类）：

- 类型 2（属性）且 `Value[0] == ITEM_MOD_CORRUPTION`（22）；或
- 类型 23（`ITEM_BONUS_ITEM_EFFECT_ID`），且指向的是腐蚀好效果（8.3.7 掉落侧约定：装等 / 品质树不用类型 23）。

独特武器列表 **6567–6572** 同时带类型 23 和腐蚀点数，必须能剥。被动是「效果列表 + 点数列表」两条都要剥。类型 24 在本核枚举里没有名字，跟签名列表一起走，剥整条列表即可，不要单独解释类型 24。

正确顺序：过滤后的剩余 ID → 模板 `_bonusData.Initialize` → 再 `AddBonusList` 每一条剩余 → 刷新外观与法术充能。

对**已经存在的实例**调用现有 `SetBonuses` 时，它 **不会** 先 `Initialize`，会把 `_bonusData` 叠在旧状态上。净化路径必须先 Initialize 再加回保留列表。`CollectionMgr::CheckHeirloomUpgrades` 里的 `ClearBonuses()` 只服务于传家宝加载，与腐蚀无关，不要复用那条语义。

穿着时必须走与脱穿装备相同的 `_ApplyItemMods` / `ApplyRatingMod(CR_CORRUPTION)`，人物才会立刻 `UpdateCorruption()`。只改 `BonusListIDs`、不卸物品属性，面板腐蚀会停在旧值。

扣货币 1719 共 5 枚。C++ 应增加具名常量（例如 `CURRENCY_CORRUPTED_MEMENTOS = 1719`），与已有的 `CURRENCY_TITAN_RESIDUUM = 1718` 放在一起。

## 6. 净化之后

- 装备变成未腐蚀，可以再打污染物（功能 8）。2020-05-21 热修后，旧净化件也可以打；35662 按热修后规则。
- 独特武器一旦净化，商店买不回 6567–6572，只能打通用特效。这是正式服。
- 不要在净化时把物品等级改回模板；只动腐蚀列表。

## 8. 验收

进游戏操作勾选见 [验收-玛乌尔净化装等污染物.md](验收-玛乌尔净化装等污染物.md) 第 4 节。摘要：

- `.labgear` 或 `.additem` 发一件带 6553 与装等选择器的胸甲。净化后：6553 消失，装等选择器仍在。idTip 的 `BonusID` 不再列出 6553。
- 货币 1719 不足 5 枚时失败，装备不变。SavedInstances 应看到 1719 减 5，1803 不变。
- 放入未腐蚀装备时失败。
- 穿着净化：人物腐蚀下降，无尽之星光环消失（必须经过物品属性重算，不能只改加成向量）。客户端 `IsCorruptedItem` 变为假；Pawn 提示不再匹配「+N 腐蚀」；CorruptionTooltips 不再给这件装备加特效名（装备物品编号不在 `purchaseable` 里，不会误显示成瓶子）。
- 打开的应是暴雪 `ItemInteractionFrame`（BlizzMove 从 8.3.0 起登记 `Blizzard_ItemInteractionUI`），标题 Titanic Purification。

## 9. 插件交叉（本功能）

- **BlizzMove 3.0.0** 只证明客户端有物品交互窗，不提供操作码字段。
- **Pawn 2.3.37** 用提示文本认 `ITEM_MOD_CORRUPTION`。净化成功后，同一件装备的腐蚀行应消失，打分不再扣腐蚀权重。
- **CorruptionTooltips** `Summary.lua` 在角色面板上看 `GetItemStats` 的 `ITEM_MOD_CORRUPTION`。净化后该值为 0 或键不存在。
- 角色面板腐蚀条走客户端 `GetCorruption()`。调研里仍缺 DejaCharacterStats 8.3；本阶段用暴雪面板 + Pawn/CT 即可，不必等那份插件。
