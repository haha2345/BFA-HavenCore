# A1 无尽之星 — 正确做法与思路

对照：8.3.7.35662。底本：`BFA-HavenCore/`，`spell_corruption.cpp`。  
哲学：`.grok/skills/837-blizzlike-fix/references/philosophy.md` 的「总原则 / 技能 / 腐蚀 / 验收」。

本文只记**现在认定正确的做法和为什么这样选**。不记试错。真装 / ilvl 缩放标成未做边界，不写进已完成。

---

## 这份文档对齐的需求

1. 无尽之星第 1 层（`.aura` 打桩）能稳定复现：技能/法术出星，普攻不出；落星约 1 秒后奥术伤；目标叠易伤，最多 10 层，每层 +25%（用砸中前的层数）。
2. 好效果和坏效果两套管，星的脚本不进 `UpdateCorruption()`，也不改 opcode / 核心施法。
3. 后面暮光、虚空、触须能抄同一套「家、数据源、脚本层、验收」，不把星做成特例核心。
4. 测试可以靠 HavenLab / `STAR_VISUAL`，但**战斗脚本本身不能依赖插件才能工作**。

---

## 系统里星站哪

腐蚀是两套，不要写进同一个循环：

| 套 | 数据 | 代码家 | 星在不在这 |
|----|------|--------|------------|
| 坏效果 | `CorruptionEffects.db2` 10 行 | `Player::UpdateCorruption()` | **不在。** 阈值、触须减速、眼睛、彼岸之物 |
| 好效果 | 物品 Bonus type 23 → ItemEffect → 技能 | `Item.cpp` 挂光环；战斗行为在 `scripts/Spells/spell_corruption.cpp` | **在这。** 穿装才有星 |

星是「这条光环挂上之后干什么」，不是「角色腐蚀值过线套什么」。阈值、抵抗、职业过滤留在 DB2。脚本禁止 `if (corruption >= 20)`。

---

## 思路（先于代码）

1. **数据能表达的不要写 C++。** Proc 掩码、RPPM、最大层数、易伤 25%、导弹延迟、50 码选目标，都在 35662 Spell 里。脚本读 `SpellInfo`（易伤 `317265` EFFECT_2、半径 `317260` `CalcRadius`、段数 Dummy `318274/487/488` EFFECT_1），不要写死 25/50/1.11，也不要世界表。不要用 `spell_proc` 覆盖 317257（会把白字平砍加进去，和文案相反）。
2. **ID 只信 35662。** 现役 Wowhead 作废。核对顺序：客户端 DB2 → SimC `bfa-dev`（`unique_gear_bfa.cpp` + `SpellDataDump/allspells.txt`）→ 进游戏 `.aura` 验收行为。SimC 用来理解链和数字，不用来抄现役 ID。
3. **最小竖切。** 先 `.aura 317257` 打桩证明战斗，再谈 318274 真装。装等缩放和「会不会出星」分开。
4. **一条效果一个家。** 文件 `spell_corruption.cpp`，`AddSC_corruption_spell_scripts()` 必须被 `spell_script_loader.cpp` 调用，SQL 只插 `spell_script_names`。暮光以后往这个文件加，不要新建 `scripts/Corruption/`。

## 技能链（35662 + SimC dump）

```
318274 / 318487 / 318488   一段/二段/三段（隐藏、装等缩放，Trigger → 317257）
        ↓ 真装才走；第 1 层用 .aura 317257 代替
317257                     隐藏 proc 光环。RPPM 2（急速）。只认技能/法术（黄字），不认白字。
                           Dummy 25 / Dummy 10 = 易伤%、层数上限（给脚本读，不是自己打伤）
        ↓ PreventDefault 后由脚本丢星（避免核心默认 Trigger 317260 和脚本各丢一次）
317260                     Dummy，50 码选附近敌人。备用入口，同一套 CastInfiniteStar
317262                     落星。学校奥术。Velocity 1（Missile Speed is Delay → 约 1 秒）。
                           目标 DEST_DEST (87)，必须对落点施放，不能当单位导弹
317265                     砸中：奥术伤（DBC BP=0，脚本填）+ 目标易伤光环（effect 3 = 25%，最多 10 层）
324889 / 324890 / 324891   物品外壳名「腐蚀 - 无尽之星 1/2/3」。DBC 无光环效果。
                           AfterCast 给自己套 317257（.aura 外壳不会跑 AfterCast，要用 .cast triggered）
```

伤害学校是**奥术**，不是暗影。

Proc 真相在 317257 的 DBC：黄字近战/远程、敌对法术、周期、陷阱等。白字平砍不在掩码里。这是设定，不要用 `spell_proc` 改成普攻出星。

## 正确实现

代码：`BFA-HavenCore/src/server/scripts/Spells/spell_corruption.cpp`  
SQL：`sql/updates/world/2026_08_24_00_world_corruption_infinite_stars.sql`  
注册：`spell_script_loader.cpp` 调用 `AddSC_corruption_spell_scripts()`。

### 入口

| 技能 | 脚本 | 做什么 |
|------|------|--------|
| 324889/90/91 | SpellScript AfterCast | 给自己 `CastSpell(317257, triggered)` |
| 317257 | AuraScript `OnProc` | `PreventDefaultAction()`，对一个敌人 `CastInfiniteStar` |
| 317260 | SpellScript Dummy | 解析命中单位后同样 `CastInfiniteStar`（核心若仍 Trigger 这条，走同一函数） |
| 317265 | SpellScript `OnHit` | 填奥术伤；乘以**本星落地前**的层数 × SpellInfo 易伤% |

施法处禁止裸数字，一律 `enum InfiniteStarsSpells`。

### `CastInfiniteStar`（唯一打星函数）

1. 目标非法、已死、是自己：返回。  
2. 317262 上有 1.5s 冷却则返回（防 317257 与 317260 各打一次，或同帧多目标）。RPPM 仍由 DBC 管频率。  
3. 对**目标位置** `CastSpell(pos, 317262, …)`（DEST，不是单位）。延迟取 `SpellInfo::Speed`，没有则 1 秒。  
4. `BasicEvent` 在延迟后再 `CastSpell(target, 317265)`。伤和叠层发生在落星之后，不是 proc 当下。  
5. 视觉只走 DEST 的 317262 SpellGo。GM 在线时打一条 `STAR_VISUAL` 给 HavenLab；默认战斗不发聊天。

### 伤害

DBC 317265 effect 1 学校伤害 BP=0，必须脚本填。当前第 1 层（无真装）读 318274 系 Dummy，**不是** 1.11/2.76/4.15：

```
rank = 318488/324891 → 318488；318487/324890 → 318487；其余（含裸 317257）→ 318274
damage = max(AP, SP) × (rank EFFECT_1 BasePoints / 100)
```

一段 83%、二段 208%、三段 312%（35662 `$s2/100*$max($AP,$SP)`）。AP/SP 已含全能，不再乘 tooltip 的 vers。

然后 `AddPct(damage, 易伤% × 砸中前层数)`，易伤% 读 317265 EFFECT_2（25）。317265 会在同一次命中里叠层，所以读到的层数要减 1 再乘，和 SimC「先伤后叠」一致。  
`DealDamage` 奥术。层是目标身上的 317265，不是玩家 buff。

1.5s 防连打**不是** DBC 字段，留在 C++，防止 317257 与 317260 各丢一颗。

真装 318274 的 `average(item)` 装等基数**还没接**。接的时候只改伤害数字来源，不要改 proc / 落点 / 延迟 / 易伤读取。

### 不要做

- 不要 `spell_proc` 覆盖 317257。  
- 不要把星写进 `UpdateCorruption()`。  
- 不要对单位目标丢 317262（DEST 会变成从身上飞出的弹，动画不对）。  
- 不要在 proc 当下立刻打 317265（没有落星时间）。  
- 不要用现役 Wowhead 数字当 35662 伤害。

## 怎么验收（第 1 层）

`.aura 317257`，用**技能**打木桩（猛击等）。HavenLab：

- 白字普攻：没有 317265。  
- 技能：`STAR_VISUAL spell=317262 visual≠0 missile=1`，约 1 秒后 `317265` 奥术，目标叠层。  
- 第二颗伤 = 第一颗 × 1.25（未暴击时）。一段 Dummy 是 83%，第一颗绝对值会低于早期 1.11 打桩（980→1225）；比例仍应 ×1.25。visual=93802。

`.aura 324889` 只有外壳图标、AfterCast 不跑，这是 DBC，不是脚本坏了。要用 `.cast 324889 triggered` 才会套 317257。

第 2b 真装（穿上 318274 自动出星、脱掉停止、ilvl 伤）**未做**，不纳入本条完成。

## 和哲学对一下：路线有没有问题

### 对齐的（保证独立性和家）

- 两套腐蚀没混。星不碰坏效果表，坏效果不碰星的 SpellScript。  
- 没改 `src/server/game/` 施法核心、opcode、UpdateFields。邻居系统（职业技能、词缀、团本）不吃这套脚本。  
- 家在 `scripts/Spells/` + `spell_script_names`，loader 有真正调用。SQL 只追加 updates。  
- ID 来自 35662 / 游戏内 lookup / SimC dump，不是 12x。  
- 一条竖切验收过进游戏，不是「文件在磁盘上」。  
- 频率、层数上限、易伤百分比、导弹延迟、选目标半径跟 DBC；脚本只补「BP=0 的伤」和「DEST 落星 + 延迟结算」——数据表达不了的那一段。

后面暮光/虚空/触须按同一形状：各自 AuraScript/SpellScript，共用这个 cpp，**不要**抽一个「腐蚀管理器」往核心里塞。

### 已收口（写暮光前）

0. **2026-08-26 修双倍扣血并重验通过**：317265 的 OnHit 曾同时 `DealDamage` + `SetHitDamage`。现在只 `SetHitDamage`。HavenLab `.labstars`：8495→10618 暴击（÷1.5 后 5663→7079 = ×1.25），每颗星战报 1 条。无层基数 ≈ max(AP,SP) × 83%。

1. `STAR_VISUAL` 只在 `IsGameMaster()` 时发系统消息；非 GM 战斗安静。HavenLab 测星仍开 `.gm on`。  
2. 施法旗改为 `InfiniteStarsCastFlags()`：忽略 GCD / 当前施法 / 消耗 / 朝向，**不含** `CAST_DIRECTLY`、`IGNORE_TARGET_CHECK`。  
3. 视觉只走 DEST 的 317262 SpellGo，去掉三路 `SendPlaySpellVisual`。  
4. 延迟事件只存 `ObjectGuid`，落地时 `FindUnit`。  
5. 1.5s 冷却只防 317257/317260 双入口，不再叠第三层；RPPM 仍走 DBC。  
6. 打星只走 `CastInfiniteStar`。317257 `PreventDefaultAction`；317260 作备用，靠 317262 冷却去重。新效果不要「PreventDefault 同时又指望默认 Trigger」。

### 结论

路线**没有把腐蚀做成核心补丁，也没有和坏效果缠死**。独立性：好效果 = ItemEffect 光环 + SpellScript；坏效果 = `UpdateCorruption` + DB2。稳健性：数据驱动 proc/层数/延迟，脚本只补 DBC 空 BP 和 DEST 落星。

## 给下一条效果抄的模板

1. 35662 dump / DB2：驱动、导弹/AT、伤害、层数各是哪个 ID。  
2. `spell_corruption.cpp` 里新 enum + 新 Script，`spell_script_names` 新 SQL 文件。  
3. `.aura` 驱动打桩；HavenLab 盯伤害 ID 和层，视觉用服务器「已发包 + visual≠0」，不靠人眼当主验收。  
4. 不改 `UpdateCorruption`，不覆盖 DBC proc 去「方便平砍」。  
5. 真装/ilvl 整条签名都打桩后再做一次共用管道。
