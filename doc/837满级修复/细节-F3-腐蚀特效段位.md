# 功能 3 细节：腐蚀特效段位 2 / 3 的获取与验收

对照 **8.3.7.35662**。设计正文：[2026-08-29-corruption-loot-ranks-design.md](../../docs/superpowers/specs/2026-08-29-corruption-loot-ranks-design.md)。  
战斗数字仍以 [腐蚀特效清单.md](腐蚀特效清单.md) 为准。本文件只回答 **高段从哪来、池子里有哪些段、怎样验收**。

## 1. 旧说法作废

剩余清单里曾写「幻象 / 突袭掉一段，心之密室用回响升段」。第二轮交叉验证：

- Icy Veins、Wowpedia、Ask Mr. Robot：掉落时直接随机到段 1 / 2 / 3（有例外，见下）。
- 玛乌尔「保存的污染物」是 **2020-05-19** 才上的指定段购买，用尼奥罗萨回响（货币 1803）。那是确定性补齐，**不是** 2 / 3 段出现的前提。
- 本阶段不做玛乌尔、不做幻象 / 突袭地图。功能 3 成功标准是：**随机池含各特效正式服存在的每一段，并能用真装验收求和。**

## 2. 与功能 4 的关系

功能 3 没有独立掉落表。功能 4 抽出「一条特效」时，候选必须覆盖下表全部合法段。若实现只把一段加成放进组，功能 3 失败。

## 4. 难度和渠道会不会改段位

**不会。** 团本寻找团队 / 普通 / 英雄 / 史诗只改物品等级。随机段位是抽中腐蚀之后再随机 1 / 2 / 3（须臾洞察等例外除外），不是「寻找团队一段、史诗三段」。

依据：Ask Mr. Robot 用 430 与 485 对比，同一条暴击腐蚀仍是 6% / 9% / 12%；加成组 158 共 69 条的物品等级选择器全是 0，没有「装等不够不出 3 段」的门槛；Wowhead / Icy Veins 把段位写成独立随机层。PTR 期有人把腐蚀 Tier 写成普通/英雄/史诗，那是误传。

2020-01-23 热修后，无尽之星等 **触发伤害** 按该件物品等级计算。史诗件上的同一段可以打得更痛，那是装等，不是抽到了更高段。

渠道（大秘、PvP、幻象）共用同一随机效果池，不另做「幻象只能一段被动」的目录。本阶段不做幻象；团本尸体掉落保持「有几率」，禁止把幻象必腐蚀抄过来。

禁止 `if (mythic) rank3`。段位权重未知，实现用过滤后池内均权，配置注释写明非 35662。

## 5. 战斗侧已经具备的验收能力

`spell_corruption.cpp` 的 `SumCorruptionRankDummy` 对仍在身上的各段驱动求和。功能 3 不改此函数。缺的是 **身上要有二段 / 三段的 ItemEffect**。

`.additem <物品> 1 6553` 这类命令已经能发二段无尽之星，可作战斗回归。功能 3 仍要求掉落池能自然抽出高段，否则只是 GM 发装，不算本功能完成。

## 6. 验收

- GM：胸甲分别带 6552 / 6553 / 6554，无尽之星伤害段差与 Dummy 一致。
- GM：6546 只能一段；尝试再叠一条「须臾洞察二段」加成若不存在于 35662，不得手造。
- 掉落：同一可腐蚀物品多次生成，日志或插件记下出现过的加成编号，集合中须含至少一条二段、一条三段签名或被动。
- 虹吸者三段必须是 45 点腐蚀（6614），不要误挂 20 点（6465）。
