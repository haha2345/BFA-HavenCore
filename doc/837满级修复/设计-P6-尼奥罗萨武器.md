## 1. 这是第三套，不要和前两套混

| 套 | 数据 | 玩家感知 | 本阶段 |
|----|------|----------|--------|
| A 装备好效果 | Bonus type 23 → ItemEffect → `腐蚀 -` 外壳 / 318xxx 段位驱动 | 随机腐蚀装 | 已做（P5 管道待进游戏） |
| B 总腐蚀坏效果 | `CorruptionEffects.db2` 10 行 | 有效腐蚀过阈值 | 已做脚本，多数待关账 |
| **C 武器写死** | 尼奥罗萨特定武器的**固定** ItemEffect + 固定腐蚀点数 | 那一把武器自带，净化一起去掉 | **本文** |

武器**没有** `腐蚀 -` 外壳前缀。脚本禁止 `if (corruption >= 20)`。阈值仍只属于 B。C 层脚本可以读物品等级做伤害，不读总腐蚀值。

穿脱已经走 `Player::_ApplyItemMods` → `ApplyItemEquipSpell`（读 `item->GetEffects()`，含 bonus type 23）。2026-08-29 已把「实例上的 ItemEffect」接到这条管道。P6 **不要**把六条武器塞进 `spell_corruption_rank_driver` 的多段家族表——它们是单驱动，不是 1/2/3 段随机腐蚀。

驱动若是光环 285（`SPELL_AURA_LINKED_2`），核心 `HandleAuraLinked` 会自己挂/摘隐藏 proc。**不要**再把武器驱动塞进 `FindCorruptionDriverFamily`——会和 LINKED 双通道打架。P5 的 `spell_corruption_rank_driver` 只服务多段随机腐蚀。

## 4. 六条效果的正式服行为（两遍核验后的定案）

第一遍：清单 + Icy Veins + wiki。第二遍：SimC `bfa-dev` 源码、Wago 8.3.7.35662 SpellEffect、Wowhead 效果类型、bonus 表、玩家实测，专门打矛盾。本文件写成后，[本地管道](decb3015-bfc6-4ec3-b58b-c95ae9e83ff3)、[吞噬灼热](7ba38e15-da29-4e6f-aab7-2582b5f19ee0)、[低语法器](33217a87-684f-4d57-a338-4dd41e7ac89d)、[实现路径](cd7d0efb-ca8c-447c-a075-d3542d351eec) 四次独立核验又改过下列挂钩，以本节为准。

下面每条先写**采用的行为**，再写**和清单/SimC 的差异**。

### 4.1 吞噬活力（Devour Vitality）

**链（SimC `corruption::devour_vitality`）**

```
ItemEffect 116812 → 318294（光环 285 LINKED_2 → 316615，BP=2）
316615：ProcChance 25%，ProcFlags 仅近战白字（mask0=0x4），无 RPPM、无 ICD
316615 PROC_TRIGGER_SPELL → 316617
```

**行为**

- 只有**近战自动攻击**（白字）能触发。英勇打击、猛击、出血不算。
- 触发几率走 316615 的 DBC `ProcChance`（25%）。禁止写死 25。不是 RPPM，ICD 为 0。
- 316617：暗影学校。Wago 35662 效果类型 9 = `SPELL_EFFECT_HEALTH_LEECH`（吸取生命）。**一条效果同时伤和疗**，不是「学校伤害 + 另一次治疗」。
- 伤害 = **施法者当前最大生命 × 2%**（318294 / 316615 的 BP=2）。不是目标最大生命。无装等系数。
- 本核 `EffectHealthLeech` 用的是效果局部 `damage`（`CalculateDamage` / `SetEffectValue` 之后），**不是** `GetHitDamage()`。`OnHit` + `SetHitDamage` 只会补上扣血、治疗仍是 0。正确挂钩：`OnEffectHitTarget` + `SetEffectValue(maxHP × 2%)`，让核心自己 `HealBySpell`。禁止再 `DealHeal` / `DealDamage`。
- 能暴击（2020-10-16 蓝贴按「预期暴击」修过）；暗影不吃护甲。射程 100 码，不要用武器近战距离卡死 316617。
- 会拉未进战的怪。双手杖，不存在双持两把。

**脚本补 / 禁**

- 补：316615 `PreventDefault` 后施放 316617；316617 `SetEffectValue`。mask0 已是平砍，**不必** `spell_proc`。
- 禁：`OnHit`/`SetHitDamage` 当吸取生命的填数手段；手写治疗；黄字也吃。

**Lab**：`.lab test devour` 挂 316615。平砍出 `DEVOUR_PROC`，CLEU 一条 316617 暗影伤 + 自己回血。技能打桩不应出。

### 4.2 灼热烈焰（Searing Flames）

**链（SimC `corruption::searing_flames`）**

```
ItemEffect → 318293
隐藏叠加光环 316703（最多 30 层，名字 Searing Flames）
满层立刻施放 316704 Searing Breath，然后清空层
```

**行为**

- 文案：「Your **damaging abilities** build stacks」。叠到 **30 立刻喷**，不是超过 30 再等下一击（`316703` CumulativeAura=30，到不了 31）。
- Wago 35662：`316698` 的 `ProcTypeMask_0=0`、`ProcTypeMask_1=0x4`（施法成功）。本核 `SpellInfo.cpp` **只把 mask0 读进 `ProcFlags`**，也没有 `ProcFlags2` 列。进游戏会变成 `ProcFlags=0`，永远不叠。必须像虚空回响那样插 `spell_proc`，复原的是本核认识的 **mask0 = 69904**（黄字近战/远程 + 敌对无伤害类型/魔法），`SpellTypeMask` 只开伤害（把治疗挡掉），`Cooldown=100`。**不要**幻想把 mask1 写进不存在的列，也**不要**抄 SimC 的 `PF_ALL_DAMAGE` + `CAST_HEAL`。
- 白字平砍不叠。周期跳伤不叠。治疗默认不叠（文案是 damaging）。无公共冷却的黄字伤害技能要叠。ICD **100 毫秒**（防一次多段命中叠多层）。
- 316704：暗影焰（火+暗）。目标 **`TARGET_UNIT_CONE_ENEMY_104`**，半径 12 码，锥角 **60 度**（`SpellTargetRestrictions.ConeDegrees`）。**不要写 `FilterTargets`**，信核心锥形。2020-02-04 热修：必须视线；不要 `Ignore LOS`。每目标满额 5% 生命，**不均摊**，不抄 SimC `aoe_proc_t` 的 +15%/6 目标。
- 伤害 = 施法者最大生命 × 5%。BP=0 则 `SetHitDamage`。会拉怪。能暴击。
- `316703` 时长 -1：**脱战不清层**。`316698` 卸下时脚本必须摘掉 `316703`，否则会裸喷。
- Faralos 是单手剑，可双持两把。默认：**两条 proc、同一条层、喷火仍是 5% 一次**（叠得更快）。不要把 5% 加成 10%。SimC 双倍喷伤不采用。

**脚本补 / 禁**

- 补：`spell_proc` 复原 316698（mask0=69904、只伤害、ICD 100ms）；30 层立刻喷 316704 并摘 316703；`316698` OnRemove 清层；`316704` `SetHitDamage`。C++ `DoCheckProc` 不要再滤「必须有公共冷却」（无 GCD 黄字也叠），也不要滤「必须打出伤害数字」（ICD 已经防多段）。
- 禁：`FilterTargets`（已是 CONE_104）；均摊；治疗/白字叠层；两把武器把 5% 加成 10%；`Ignore LOS`。

**Lab**：`.lab test searing` 挂 316698。伤害技能叠到 30，CLEU 一条 316704，层清零。身后桩不应吃。平砍不应叠。

### 4.3 低语真相（Whispered Truths）

**链（SimC `items::whispering_eldritch_bow`）**

```
ItemEffect → 316780（被动，自动射击 proc）
清单写 Trigger 316782（Misc 3 = 随机猎人技能）
SimC 不施放 316782，直接在回调里减 CD
```

**行为**

- 只有**自动射击**触发（`PROC_FLAG_DONE_RANGED_AUTO_ATTACK`）。自动射击是技能，`GetProcSpell()` **不是**空指针——不要用「空指针才算平砍」去滤，否则弓完全不触发。
- 触发几率 101%，**没有 RPPM、没有 ICD**。Dummy 2000 是削减量（热修 1000→2000），不是内置冷却。急速只让射得更勤。
- 第 1 层 `.lab test` **不要**写 `getClass() == CLASS_HUNTER` 门闩：测试命令只 `AddAura`，战士号会静默不触发。真装是猎人弓，非猎人穿不上。验收说明写清：自动射击只有猎人号才打得出来。
- 在**当前正在冷却**的职业技能里均匀随机一个，减去 2.0 秒。没有技能在冷却上则空过。谓词抄 `TryGlimpseTrim` 的内联条件（有法术族、非被动、非触发、非物品、有恢复时间或充能），**不要**改 Glimpse 本身。充能技能同时走 `ReduceChargeCooldown`。
- 本核 API 是 `getClass()`，不是 `GetClass()`。
- **禁止**抄 SimC `whispered_truths_offensive_chance`（75% 进攻偏向）。
- 316782 是脚本入口 / 可能的 CLEU；dump 写了 8 层上限，没有对应玩法，**忽略**。MiscValue 3 不是 DBC 随机技能表。

**Lab**：猎人 `.lab test whisper` 挂 316780。先开一个职业技能让转盘转。自动射击出 `WHISPER_PROC`。

### 4.4 灵光一闪（Flash of Insight，法器；不要叫须臾洞察）

**不是**随机腐蚀那条 Glimpse of Clarity（318239 / 315574 / 315573，减下一次技能 CD）。现役简体把法器标成 **灵光一闪**，把随机装标成须臾洞察。仓库已把 318299 / 316717 放进 `IsGlimpseExcludedSpell`，**行为尚未实现**。

**链**

```
ItemEffect → 318299（LINKED_2 → 316717）
316717：RPPM 2.5（dump 无急速倍率）+ ICD 10 秒，只认法术掩码
316717 LINKED → 316744，最多 8 层，每层 1%
316744：Aura 137 SPELL_AURA_MOD_TOTAL_STAT_PERCENTAGE（热修 80→137），MiscValueB=8（智力）
```

**行为**

- 每次 proc：**把层数重滚成 1..8（含两端）**，不是 +1。SimC `rng().range` 几乎抽不到 8，那是模拟器瑕疵。
- 「at all times」：挂上 316717 时**立刻**滚一次 316744。脱战层数保持（时长无限），脱掉武器才掉。
- 只认法术。平砍、宠物、黄字射击不 proc。
- `DoEffectCalcAmount` 只填**单层** 1%，引擎再乘层数。禁止脚本里 `amount * stacks`（会变成最高 64%）。
- 百分比作用在**总智力**（Aura 137），不是基础智力。百分比本身不随装等缩放。
- 可副手（织雾 / 奶萨）。不能同时两把玛寇瓦。

**Lab**：智力职业 `.lab test flash` 挂 316717。身上立刻有 316744，层在 1–8。施法后层层数跳到另一个 1–8，不出现 9。面板智力随层变。

### 4.5 虚空之鞭（Lash of the Void）

**链（35662 + SimC hotfix，[虚空鞭与黑曜石核验](52eb763c-5a71-46f2-9130-e289bd3dfe07)）**

```
ItemEffect 116814 → 317290（被动 Dummy：RPPM 2 吃急速、装等系数、减速语义）
热修把 Trigger 清 0，引擎不会自己放伤害
脚本 PreventDefault 后施放 317291（9 码 / 60 度暗影锥）
317291 EFFECT_1 TRIGGER → 319241（−30% 诱捕，6 秒）
```

**行为**

- 热修后掩码 **4 = 仅白字近战平砍**（SimC：`Proc Flags (69908 -> 4)`；35662 `SpellAuraOptions.ProcTypeMask=4`）。黄字、周期都不吃。副手白字算。Icy Veins 仍写 “Your attacks” 是热修前残文；[第二遍打脸六条武器](3641eeb2-446b-4da4-afe7-dc44fdc49774) 因没拆到 DBC 掩码，曾主张「仍是攻击触发」——**实施方案跟 35662 掩码 4**。Task 0 若转出不是 4，再改 `DoCheckProc`，不要先写宽。
- RPPM **2**，吃急速。不要 `spell_proc`（掩码已经在 mask0）。
- 伤害 = `317290` 效果 1 的 `CalcValue(..., itemId, itemLevel)`，系数 **40.058**，攻击强度系数已热修成 0。禁止写死 40.058，禁止按 AP×30%。
- `317291`：暗影学校伤害，面前锥形，**9 码、60 度**，目标数不封顶。SimC `aoe=-1` 只表示不截人数，**不是**无限半径。不要 `FilterTargets`。
- 减速走 DBC 链 `317291 → 319241`，不要另造光环。驱散类型无，机制诱捕。
- **禁止施放 `317292`**（35662 仍是 300 码秒杀）。
- 会拉怪。双持两把 Unguent：两份 `317290`、两套 RPPM（战士穿不上拳套）。
- 第 1 层 `.lab test` 无铸物时 `itemLevel=-1`，伤害会偏小，验收看「出伤 + 锥形 + 减速」，不看绝对数字。

**脚本补 / 禁**

- 补：`317290` OnProc 填 `CastCustomSpell(317291, SPELLVALUE_BASE_POINT0, CalcValue)`；`317291` 若 BP 仍被覆盖失败再 `SetHitDamage`。
- 禁：把伤害打在 317290 自己身上；无限半径；`spell_proc` 改回 69908。

**Lab**：近战 `.lab test lash` 挂 317290。平砍出 `LASH_PROC` + 锥形暗影伤 + 6 秒减速。猛击不应出。身后桩不应吃。

### 4.6 黑曜石皮肤（Obsidian Skin）

**链**

```
ItemEffect 116817 → 316651
  EFFECT_0：光环 101 MOD_RESISTANCE_PCT，物理 +5% ← 零脚本（不是 Dummy）
  EFFECT_1：Dummy 30（30 层 / 30 秒语义）
  EFFECT_2：Dummy 700（护甲 ×700%；热修 300→700，35662 已是 700）
  EFFECT_3：光环 285 LINKED_2 → 317420
317420：Periodic Dummy 1 秒，最多 30 层，时长 −1（叠层，不打伤害）
满层下一跳（或进战斗时已是 30 层的本跳）：施放 316661，层回到 1
316661：自身周围 20 码暗影 SCHOOL_DAMAGE，BP=0
```

**行为**

- +5% 护甲穿上就有，进不进战斗都有。不要再写一套百分比脚本。
- 战斗中每秒 +1 层。脱战**停加不清层**（Rextroy 连招 / Maut 掉落指南）。SimC 进战斗重置为 1 **不采用**。
- 进战斗时若已经 30 层：本周期第一跳就炸（最多等 1 秒）。不要另写 PlayerScript 抢「立刻」。
- 炸完回到 **1** 层，不是 0。
- 316661 伤害 = **当前护甲**（含这 +5%）× Dummy3%。禁止写死 700/300；fallback 700 并 ERROR 一次。wiki 300 是 PTR / 缩水 tooltip。
- 2020-01-28 热修：爆炸在命中目标间**分摊**，且随目标数加一截总伤，**6 个封顶**。DBC 无此字段。默认抄 SimC：`总伤 × (1 + 0.15 × (min(人数,6) − 1)) / 实际人数`。进游戏用 1 / 2 / 6 个桩校准；不要把这个 15% 用到灼热吐息上。
- 要视线（01-28 与灼热同一条热修）。能暴击、吃全能。会拉怪。
- 狂暴战泰坦之握**可以**双持两把双手斧。正式服爆炸**不叠加**（Blizzard Watch：第二把可以净化，因为 AoE 不会叠）。同一 `316651` 默认叠不成两份。不要抄 SimC 护甲%/伤加倍。

**Lab**：`.lab test obsidian` 挂 316651。进战斗层涨，满层 CLEU 316661，层回 1。脱战层还在。20 码外不受伤。关 god 看护甲×系数。

## 5. 宏观架构

```
穿上尼奥罗萨武器
  → Item bonus 6567–6572 带来腐蚀点数（走 ITEM_MOD_CORRUPTION → UpdateCorruption，B 套坏效果照常）
  → ItemEffect ON_EQUIP 挂 318294 / 316780 / 317290 / 318299 / 318293 / 316651
  → （若 LINKED）隐藏 proc 自动出现
  → spell_corruption.cpp 只实现「光环挂上之后的战斗行为」
脱掉 / 净化
  → ApplyEquipSpell(apply=false) 摘光环，行为停
```

不新建「武器管理器」。不改 `UpdateCorruption()` 循环。不搬 opcode。核心只修真 bug（P6 预期不需要）。

伤害统一形状（沿总纲）：

- 学校伤害：`SetHitDamage` / `SPELLVALUE_BASE_POINT0`
- 吸取生命（316617）：`OnEffectHitTarget` + `SetEffectValue`，让 `EffectHealthLeech` 自己伤和疗
- 周期只 `DoEffectCalcAmount`（只填单层）
- 禁止再叠 `DealDamage` / `DealHeal`
- 跨帧只传 GUID
- 每目标独立暴击

## 6. 实现路径（2–3 种）
